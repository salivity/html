How to Use the HTML Var Element

The HTML <var> element is a semantic tag specifically designed to define variables in mathematical expressions, computer code, and technical documentation. By wrapping a variable name in <var>, developers provide semantic meaning to search engines, screen readers, and browsers, indicating that the enclosed text represents a placeholder value rather than literal text. This article covers how the <var> element works, its default styling, practical use cases in programming and mathematics, and best practices for combining it with other technical HTML tags.

Semantic Purpose of the <var> Element

The <var> element denotes an instance of a variable. A variable, in this context, can be:

  • A mathematical variable (e.g., \(x\), \(y\), or \(n\)).
  • A programming variable or constant.
  • A function parameter or argument.
  • A placeholder in a command-line interface or template where the user is expected to supply a value.

Using <var> instead of generic formatting tags like <i> or <span> preserves the semantic structure of the document. While visual browsers primarily italicize the content, assistive technologies and search engine parsers recognize the tag as a programmatic or mathematical entity.

Default Browser Presentation

By default, modern web browsers apply the following User Agent style to the <var> element:

var {
  font-style: italic;
}

Because variables in traditional typography and mathematics are typically italicized, the default style fits standard publishing conventions. However, this appearance can be customized using standard CSS.

Using <var> in Mathematical Expressions

In mathematical writing, <var> identifies letters that stand for changing or unknown values, distinguishing them from operators, constants, and standard text.

<p>According to the Pythagorean theorem, <var>a</var><sup>2</sup> + <var>b</var><sup>2</sup> = <var>c</var><sup>2</sup>, where <var>c</var> is the hypotenuse.</p>

In this example, the letters \(a\), \(b\), and \(c\) represent variables, while the numbers, superscripts, and operators represent mathematical operations.

Using <var> in Programming and Code Contexts

In software documentation, <var> is frequently combined with elements like <code>, <pre>, and <kbd>. While <code> denotes literal computer code, <var> denotes dynamic placeholders within that code that a developer must replace.

Example: Function Signatures

<p>The function signature is defined as: <code>function calculateTotal(<var>subtotal</var>, <var>taxRate</var>)</code>.</p>

Here, calculateTotal is literal code, while <var>subtotal</var> and <var>taxRate</var> represent variable arguments.

Example: Command-Line Placeholders

<p>To clone a repository, run: <kbd>git clone https://github.com/<var>username</var>/<var>repository</var>.git</kbd></p>

In this terminal instruction, the user must substitute their actual account name and project name for the marked variables.

Distinguishing <var> from <i>, <em>, and <code>

  • <var> vs. <i>: The <i> element represents text in an alternate voice or mood (e.g., technical terms, foreign phrases) without conveying structural meaning. <var> should always be used when the text is specifically a variable.
  • <var> vs. <em>: The <em> tag indicates stress emphasis, altering the spoken inflection of the sentence. A variable rarely represents vocal stress.
  • <var> vs. <code>: The <code> element indicates literal computer code (keywords, fixed function names). When a code snippet contains dynamic inputs, <var> should be nested inside <code>.

Custom Styling with CSS

While italics are appropriate for algebra, programming documentation often requires variables to match the monospaced font of surrounding code. You can override default styles using CSS:

code var {
  font-family: monospace;
  font-style: normal;
  color: #c7254e;
}

This keeps the semantic value of <var> intact while adjusting the visual presentation to suit coding conventions.
