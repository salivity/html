Reset vs Submit Button in HTML Forms

In an HTML <form>, the submit and reset buttons serve opposite functional purposes for handling user input. A submit button transmits the entered form data to a web server or processing script defined in the form's action attribute. In contrast, a reset button restores all input fields, checkboxes, radio buttons, and dropdown menus within that form back to their initial default values, without sending any data over the network.

The Submit Button (type="submit")

The submit button is the primary mechanism for finalizing data entry. When activated, either by a mouse click, tap, or by pressing the "Enter" key within an input field, it initiates the browser's form submission process.

  • Default Behavior: In modern HTML, <button> elements placed inside a <form> default to type="submit" unless explicitly given another type.
  • Data Transmission: It gathers all successful form controls (fields with a name attribute and valid values) and serializes them according to the form's method (such as GET or POST) and enctype.
  • Validation: Before submission, the browser automatically executes built-in HTML5 validation checks (such as required, pattern, or minlength). If any field fails validation, submission is blocked.
  • Syntax Examples:
    • <input type="submit" value="Send Message">
    • <button type="submit">Send Message</button>

The Reset Button (type="reset")

The reset button restores the form to its original state as defined when the page was first loaded.

  • Restoration, Not Clearing: A common misconception is that a reset button clears all inputs to blank. Instead, it resets each field to its baseline markup value. If an input originally contained value="John", clicking reset returns the field to "John", not an empty string.
  • No Network Activity: The reset action happens purely within the client's browser. No HTTP request is generated, and no data is sent to the server.
  • No Validation Checks: Triggering a reset bypasses form validation entirely, as no data is being processed.
  • Syntax Examples:
    • <input type="reset" value="Reset Form">
    • <button type="reset">Reset Form</button>

Key Differences at a Glance

Feature Submit Button (type="submit") Reset Button (type="reset")
Primary Purpose Sends data to a server or script. Restores fields to initial values.
Network Request Yes (via GET, POST, etc.). No (client-side only).
Triggers Validation Yes (validates required, patterns, etc.). No.
Default Button Type Yes (inside <form> tags). No (must be explicitly declared).
JavaScript Events Triggers submit event on the form. Triggers reset event on the form.

Modern Usability Considerations

While both buttons are standard HTML specifications, user experience (UX) best practices discourage the frequent use of reset buttons. Users rarely intend to wipe out all the information they have typed, and placing a reset button adjacent to a submit button often leads to accidental data loss. Consequently, almost every functional form requires a submit button, while reset buttons are typically omitted.
