Using HTML Address Element for Author Contact Info

The HTML <address> element is a dedicated semantic tag used to provide contact information for the author or owner of a document or an article. This article explains the semantic meaning of the <address> tag, how it associates contact details with specific content depending on its placement in the DOM, what types of information it should contain, and common mistakes to avoid.

Semantic Scope and Placement

The context of the <address> element determines whether it applies to an entire document or a specific section:

  • Document-level authorship: When placed directly within the <body> element (often inside the <footer> of the page), the <address> element represents contact information for the author, maintainer, or owner of the entire web page or website.
  • Article-level authorship: When placed inside an <article> element, the <address> element applies exclusively to the author of that particular article.

What to Include Inside the Element

The <address> tag is meant to hold any form of contact information relevant to the author. Valid content includes:

  • Author or editor names
  • Email addresses (typically wrapped in <a href="mailto:...">)
  • Links to personal websites, profiles, or social media handles
  • Physical mailing addresses or office locations
  • Phone numbers

  <h2>Understanding Modern Web Standards</h2>
  <p>Web standards ensure consistency and accessibility...</p>
  
  <footer>
    <address>
      Written by <a href="https://example.com/author">Jane Doe</a>.<br>
      Email: <a href="mailto:jane@example.com">jane@example.com</a><br>
      Follow on Twitter: <a href="https://twitter.com/janedoe">@janedoe</a>
    </address>
  </footer>
</article>

Common Misconceptions

A frequent mistake is using the <address> element for any arbitrary postal address, such as a company's office address in a store locator or an address mentioned in a news story. The element is strictly reserved for author contact information. If a physical address does not describe how to contact the author or publisher of the content, standard paragraph (<p>) or <div> tags should be used instead.

Additionally, the <address> element should not contain general publication metadata like publication dates or copyright notices, which should instead be marked up using elements like <time> and <small>.

SEO and Accessibility Impact

By default, browsers render the contents of the <address> element in italics. Beyond visual styling, semantic markup allows search engine crawlers to accurately map author attribution and contact mechanisms to specific web documents. Assistive technologies such as screen readers can identify the element, allowing users to quickly locate author details and communication channels.
