How to Use Min, Max, and Step in HTML Inputs

HTML form inputs rely on the min, max, and step attributes to enforce client-side constraints on numerical and date-based data. These attributes define the boundaries of acceptable values, establish incremental intervals, and alter native browser UI controls like number steppers and range sliders. By using these attributes, developers can validate user input automatically before form submission and reduce input errors without writing custom JavaScript.

The Applicable Input Types

The min, max, and step attributes primarily apply to numerical input types:

  • type="number"
  • type="range"

They also function on date and time input types, such as date, month, week, time, datetime-local, where the values represent chronological limits and intervals.

The min Attribute

The min attribute specifies the minimum acceptable value for an input field.

  • Behavior: If a user enters a value lower than the specified min, the field fails HTML5 constraint validation.
  • Validation State: The browser sets the input's validity.rangeUnderflow property to true and matches the CSS :invalid pseudo-class upon form submission.
  • UI Effect: In spin-button controls (number inputs), clicking the down arrow will not decrement the value below the min threshold.

Example:

<input type="number" min="1" />

In this example, any value below 1 is invalid.

The max Attribute

The max attribute defines the upper boundary for an acceptable value.

  • Behavior: Entering a value greater than the specified max prevents successful form submission.
  • Validation State: The browser sets the input's validity.rangeOverflow property to true and flags the input as invalid.
  • UI Effect: The up-arrow stepper on a number input stops incrementing once the value reaches the max limit. On a range slider, max defines the far-right or top end of the track.

Example:

<input type="number" max="100" />

In this example, any value above 100 is invalid.

The step Attribute

The step attribute dictates the granular intervals at which values are considered valid.

  • Default Value: For type="number", the default step is 1. This means decimal values are considered invalid unless explicitly enabled.
  • Calculated Baseline: Step intervals are calculated starting from the min attribute. If no min is specified, the step calculations baseline begins at 0 or the input's value. For example, with min="1" and step="2", valid values are 1, 3, 5, 7, and so on.
  • Validation State: If an entered value does not align with the step interval, the browser sets validity.stepMismatch to true.
  • The any Keyword: Setting step="any" removes the interval restriction completely, allowing any floating-point number between the min and max limits.

Example:

<!-- Allows currency increments of 0.01 -->
<input type="number" min="0" step="0.01" />

<!-- Allows any float value -->
<input type="number" step="any" />

Combined Constraint Behavior

When used together, these attributes define a strict numerical range and granularity:

<input type="number" min="10" max="50" step="5" />

In this scenario:

  1. Values below 10 or above 50 are rejected.
  2. Only values incremented by 5 starting from 10 (e.g., 10, 15, 20, ..., 50) pass validation.
  3. Native stepper controls will increment and decrement specifically across these allowed values.
