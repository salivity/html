Understanding the rel="ugc" Attribute in HTML

The rel="ugc" attribute is an HTML link microformat value designed to identify hyperlinks originating from user-generated content, such as blog comments, forum posts, and public profile submissions. Introduced by Google in 2019 alongside rel="sponsored", it allows webmasters to signal to search engines that a specific link was created by an end user rather than the site's editorial team. This article explains how the attribute functions in HTML, how search engines interpret it, and how to implement it correctly across your website.

What Is rel="ugc"?

The ugc value stands for "User-Generated Content." It is applied within the rel (relationship) attribute of an anchor (<a>) tag. Its primary purpose is to distinguish between links placed intentionally by a website's publisher and links placed dynamically or manually by visitors to that website.

Prior to its introduction, webmasters relied on rel="nofollow" to prevent untrusted or spammy user links from passing SEO link equity (often referred to as "PageRank"). The rel="ugc" attribute provides a more specific descriptor, turning what was once a binary directive into a descriptive classification.

How Search Engines Interpret rel="ugc"

When a search engine crawler encounters a link with rel="ugc", it processes the link according to the following mechanisms:

  1. Hint Model Processing: Major search engines like Google treat rel="ugc" as a hint rather than an absolute rule. While crawlers usually will not pass link authority across a UGC link, they reserve the right to use the link for discovery or contextual relevance.
  2. Spam Mitigation: By flagging user-added links, webmasters protect their domain from being penalized for outbound link spam, link farming, or manipulative link schemes executed by malicious third parties in open text fields.
  3. Contextual Recognition: It enables search algorithms to understand the architecture of web communities, separating commercial intent, editorial endorsement, and public commentary.

HTML Implementation and Syntax

Implementing the ugc attribute requires adding it directly to standard HTML anchor tags.

Basic Usage

For a standard user-submitted link (such as a link within a blog comment):

<a href="https://example.com" rel="ugc">Visit Example Site</a>

Combining Multiple rel Values

The HTML specification allows space-separated values within a single rel attribute. If backwards compatibility with search engines that do not recognize ugc is required, you can combine it with nofollow:

<a href="https://example.com" rel="nofollow ugc">Visit Example Site</a>

If a user contributes a link that is also sponsored or promotional in nature, ugc and sponsored can also be combined:

<a href="https://example.com" rel="ugc sponsored">Sponsored User Submission</a>

Where to Use rel="ugc"

The rel="ugc" attribute should be automated in platform settings or content management system (CMS) code for areas where users can post unmoderated or moderated links, including:

  • Blog Comment Sections: Text submitted via public comment fields.
  • Discussion Forums: Threads, replies, and community message boards.
  • User Profile Links: Website URLs submitted on public profile pages or author bios.
  • Product Reviews and Q&A: Content submitted by consumers on e-commerce pages.

Where NOT to Use rel="ugc"

The attribute should not be used for links created directly by site editors, staff writers, or platform owners. Editorial recommendations, reference citations, and navigation menus should remain standard links (or rel="sponsored" if paid) so that search engines can accurately measure the authentic editorial graph of the web.
