Difference Between srcset and sizes in HTML

Responsive web design requires serving the right image size to the right device to optimize performance and bandwidth. The srcset and sizes attributes work together within the standard HTML <img> tag to achieve this, but they perform two distinct roles. In short, srcset defines the list of available image source files and their actual physical dimensions, while sizes tells the browser how much layout space the image will occupy across different screen conditions.

What is the srcset Attribute?

The srcset (source set) attribute provides the browser with a comma-separated list of image files to choose from, rather than relying on a single static file specified in the src attribute.

Each item in the srcset consists of:

  1. The image URL.
  2. A descriptor indicating the image's intrinsic size or target pixel density.

There are two types of descriptors used in srcset:

  • Width descriptors (w): Specifies the native pixel width of the image file (for example, image-small.jpg 400w, meaning the file is 400 pixels wide).
  • Pixel density descriptors (x): Specifies target screen densities (for example, image-2x.jpg 2x for high-density Retina displays).

When using width descriptors (w), the browser needs additional layout context to know which image to download, which is where the sizes attribute becomes necessary.

What is the sizes Attribute?

The sizes attribute tells the browser what width the image will render at in the page layout before the page's external CSS is downloaded and parsed.

Because browsers download images concurrently while fetching CSS, the browser cannot know how wide an image will be rendered on the screen from stylesheets alone. The sizes attribute bridges this gap.

A sizes value contains a comma-separated list of:

  1. A media condition (similar to a media query).
  2. The intended slot width the image will occupy when that condition is true (using units like vw, px, em, or rem, but not percentages).
  3. A fallback slot width at the very end.

For example: sizes="(max-width: 768px) 100vw, 50vw" tells the browser: "If the viewport width is 768 pixels or less, this image takes up 100% of the viewport width. Otherwise, it takes up 50%."

Key Differences

  • Purpose: srcset defines the supply (the available files and their native dimensions). sizes defines the demand (the display width the layout will assign to the image).
  • Descriptors vs. Units: srcset uses intrinsic pixel widths (w) or display multipliers (x). sizes uses CSS length values (px, vw, calc(), etc.).
  • Dependency: sizes has no effect without srcset using w descriptors. Conversely, srcset can function on its own when using pixel density descriptors (1x, 2x), but requires sizes when using width descriptors (w) in dynamic layouts.

How They Function Together

When a browser encounters an <img> tag with both attributes:

  1. It checks the current viewport width and matches the relevant rule in the sizes attribute to calculate the image's target display width.
  2. It evaluates the device's screen pixel ratio (DPR).
  3. It multiplies the target display width by the DPR to determine the ideal pixel resolution.
  4. It scans the srcset list and downloads the smallest available image that meets or exceeds that required resolution.
