How to Use the CSS object-fit Property

The object-fit CSS property defines how replaced elements, such as <img> and <video>, adjust their width and height to fit inside their parent container. This article explains how object-fit works, details each of its five distinct values, and demonstrates how it pairs with object-position to eliminate distorted aspect ratios in modern web design.

What Does object-fit Do?

By default, applying fixed width and height values to an image or video can distort its native aspect ratio, causing it to stretch or squash. The object-fit property controls this behavior by specifying how the content should resize to fill the element's defined content box.

It functions similarly to the background-size property used on CSS background images, but applies directly to inline HTML media elements.

The Five Values of object-fit

The behavior of object-fit depends on which of the five keywords you apply:

1. fill (Default)

img {
  width: 100%;
  height: 300px;
  object-fit: fill;
}
  • Behavior: The media is resized to completely fill the specified dimensions.
  • Aspect Ratio: Ignored. The image will stretch or warp if the container’s aspect ratio does not match the image's natural aspect ratio.

2. contain

img {
  width: 100%;
  height: 300px;
  object-fit: contain;
}
  • Behavior: The media scales to fit entirely inside the container while preserving its aspect ratio.
  • Aspect Ratio: Preserved. The entire image or video will always be visible. If the aspect ratios do not match, empty space (letterboxing or pillarboxing) appears around the media.

3. cover

img {
  width: 100%;
  height: 300px;
  object-fit: cover;
}
  • Behavior: The media scales proportionally to fill the entire content box.
  • Aspect Ratio: Preserved. Any parts of the media that exceed the bounds of the container are clipped. This is the most common value used for responsive cards, hero banners, and profile avatars.

4. none

img {
  width: 100%;
  height: 300px;
  object-fit: none;
}
  • Behavior: The media completely ignores the height and width constraints of the container and displays at its original intrinsic size.
  • Aspect Ratio: Preserved. If the image is larger than the container, it will be cropped; if smaller, empty space will surround it.

5. scale-down

img {
  width: 100%;
  height: 300px;
  object-fit: scale-down;
}
  • Behavior: The media automatically selects whichever outcome between none and contain results in the smaller concrete object size.
  • Aspect Ratio: Preserved. It acts like contain if the image is larger than the box, but behaves like none if the image is smaller than the box to prevent upscaling blurriness.

Aligning Media with object-position

When using values like cover or none, parts of the image are often cropped. By default, browsers center the media within the container (object-position: 50% 50%).

You can alter which part of the media remains visible using the object-position property:

img {
  width: 300px;
  height: 300px;
  object-fit: cover;
  object-position: top center; /* Keeps the top part of the image visible */
}

This property accepts keywords (such as top, bottom, left, right, center) or specific measurements (px, %, rem) along the X and Y axes.

Practical Application

To make dynamic images fit uniformly into a responsive card layout:

<div class="card">
  <img src="user-upload.jpg" alt="Preview" class="card-image">
</div>
.card {
  width: 100%;
  max-width: 400px;
  height: 250px;
  overflow: hidden;
}

.card-image {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}

Regardless of the original dimensions of user-upload.jpg, the image fills the card uniformly without distortion.
