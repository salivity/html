HTML formaction: Multiple Submit Buttons in One Form

The formaction attribute in HTML allows developers to override a form's default submission URL on a per-button basis, enabling a single <form> element to send data to different server endpoints depending on which submit button the user clicks. This built-in attribute eliminates the need for JavaScript workarounds or redundant forms, providing a clean, accessible, and progressive-enhancement-friendly method for handling multiple actions such as saving drafts, publishing content, or deleting records.

How the formaction Attribute Works

Normally, an HTML form defines its destination endpoint using the action attribute inside the <form> tag. When a user submits the form, the browser packages the input values and sends them exclusively to that defined URL.

<form action="/save" method="post">
  <!-- All submissions default to /save -->
</form>

The formaction attribute works with <button type="submit"> or <input type="submit"> elements. When a submit button contains a formaction attribute, clicking that specific button supersedes the action attribute defined on the parent <form>. The browser routes the form payload to the URL specified in the button's formaction instead.

Code Example

A common scenario is a content editor where an author can either save an article as a draft, preview it, or publish it immediately:

<form action="/posts/save-draft" method="post">
  <label for="title">Title:</label>
  <input type="text" id="title" name="title" required>

  <label for="content">Content:</label>
  <textarea id="content" name="content"></textarea>

  <!-- Submits to the default action: /posts/save-draft -->
  <button type="submit">Save Draft</button>

  <!-- Overrides action to submit to /posts/publish -->
  <button type="submit" formaction="/posts/publish">Publish</button>

  <!-- Overrides action to submit to /posts/preview -->
  <button type="submit" formaction="/posts/preview">Preview</button>
</form>

In this implementation:

  • Clicking Save Draft sends the payload to /posts/save-draft.
  • Clicking Publish sends the identical payload to /posts/publish.
  • Clicking Preview sends the payload to /posts/preview.

Companion Form Attributes

HTML5 also provides companion attributes that can be used alongside formaction to override other form-level submission configurations:

  • formmethod: Overrides the form's method attribute (e.g., sending a POST instead of a GET).
  • formenctype: Overrides the encoding type (enctype), useful when one action involves a file upload requiring multipart/form-data.
  • formnovalidate: Bypasses HTML5 constraint validation for that specific submission (useful for "Save as Draft" buttons where not all required fields are filled).
  • formtarget: Overrides the target attribute, allowing an action to open the response in a new tab (e.g., formtarget="_blank" for previews).

Key Benefits

  1. No JavaScript Dependency: Form routing works natively in all modern browsers without custom event listeners or script-based URL rewriting.
  2. Accessible by Default: Works predictably with keyboard navigation and assistive technologies.
  3. Simpler Server Logic: Instead of routing all submissions through a single controller that parses button names to determine intent, requests can be sent directly to dedicated endpoints.
