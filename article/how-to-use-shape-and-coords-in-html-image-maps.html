How to Use Shape and Coords in HTML Image Maps

HTML image maps allow web developers to link different sections of a single image to multiple destinations by defining interactive regions known as hotspots. This article explains how the shape and coords attributes of the <area> tag work together to delineate these clickable areas. By pairing specific geometric shapes—rectangles, circles, and polygons—with corresponding pixel coordinates, you can map precise, interactive regions over any static graphic.

The Coordinate System

HTML image maps calculate coordinates based on a standard two-dimensional Cartesian grid applied to the image:

  • The origin point (0, 0) is located at the top-left corner of the image.
  • The x-axis increases horizontally from left to right.
  • The y-axis increases vertically from top to bottom.
  • All coordinate values inside the coords attribute are comma-separated integers representing distances measured in pixels.

Supported Shapes and Their Coordinates

The shape attribute specifies the geometric layout of the hotspot, while the coords attribute supplies the precise boundary measurements required by that specific shape.

1. Rectangles (shape="rect")

The rectangle shape requires four coordinate values to define its boundaries:

  • Syntax: shape="rect" coords="x1, y1, x2, y2"
  • Values:
    • x1, y1: The horizontal and vertical position of the top-left corner.
    • x2, y2: The horizontal and vertical position of the bottom-right corner.
<area shape="rect" coords="20, 20, 150, 80" href="rectangle-page.html" alt="Rectangle Hotspot">

In this example, the clickable box begins 20 pixels from the left and top edges, extending to a point 150 pixels from the left and 80 pixels from the top.

2. Circles (shape="circle")

The circle shape requires three coordinate values to define its center point and size:

  • Syntax: shape="circle" coords="x, y, radius"
  • Values:
    • x, y: The coordinates marking the center point of the circle.
    • radius: The distance in pixels from the center to the outer perimeter.
<area shape="circle" coords="200, 150, 50" href="circle-page.html" alt="Circle Hotspot">

This hotspot creates a circular click target centered at 200 pixels along the x-axis and 150 pixels along the y-axis, with a clickable radius of 50 pixels in all directions.

3. Polygons (shape="poly")

The polygon shape allows for complex, irregular, or multi-sided hotspots (such as triangles, stars, or geographical boundaries):

  • Syntax: shape="poly" coords="x1, y1, x2, y2, x3, y3, ..."
  • Values: Pairs of x and y points representing each vertex (corner) of the shape.
  • Note: A polygon requires at least three pairs of coordinates (six numbers) to form a triangle. The browser automatically closes the shape by connecting the final coordinate back to the first.
<area shape="poly" coords="100, 10, 140, 90, 60, 90" href="triangle-page.html" alt="Triangle Hotspot">

This creates a triangular hotspot connecting the three vertices at (100, 10), (140, 90), and (60, 90).

4. Default Region (shape="default")

The default shape serves as a fallback that encompasses the entire remaining area of the image not already claimed by other <area> elements.

  • Syntax: shape="default"
  • Values: It does not use the coords attribute.
<area shape="default" href="general-info.html" alt="General Area">

Practical Implementation Example

To link the coordinates to the image, the <img> tag references the <map> element's name attribute using the usemap attribute preceded by a hash symbol (#):

<img src="interface-layout.png" alt="Interface Navigation" usemap="#nav-map">

<map name="nav-map">
  <!-- Rectangular button -->
  <area shape="rect" coords="10, 10, 100, 50" href="dashboard.html" alt="Dashboard">
  
  <!-- Circular icon -->
  <area shape="circle" coords="200, 30, 20" href="profile.html" alt="Profile">
  
  <!-- Fallback area -->
  <area shape="default" href="help.html" alt="Help Center">
</map>

When a user clicks inside the defined pixel ranges, the browser detects whether the pointer coordinates fall within the boundaries established by the shape and coords values and redirects the user accordingly.
