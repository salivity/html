How to Use HTML Description Lists for Metadata

HTML description lists, defined by the <dl>, <dt>, and <dd> elements, provide a native, semantic method for structuring key-value pairs and metadata on the web. This article explains how these elements function together, how they represent diverse data relationships, how to group them for modern CSS layouts, and why they improve accessibility and search engine readability compared to generic containers.

The Anatomy of a Description List

A description list consists of three interrelated HTML tags:

  • <dl> (Description List): The parent wrapper element that establishes the scope of the key-value pairings.
  • <dt> (Description Term): Represents the "key," name, or label for the data point.
  • <dd> (Description Details): Represents the "value," definition, or description associated with the preceding <dt>.

Unlike unordered (<ul>) or ordered (<ol>) lists that only contain generic list items (<li>), a description list inherently couples labels directly to their corresponding data values.

Basic Key-Value Representation

Description lists are ideal for displaying document metadata, product specifications, glossaries, and user profile information.

<dl>
  <dt>Author</dt>
  <dd>Jane Doe</dd>

  <dt>Published</dt>
  <dd>2023-10-15</dd>

  <dt>Category</dt>
  <dd>Web Standards</dd>
</dl>

In this structure, user agents and assistive technologies recognize "Author," "Published," and "Category" as identifiers for the respective data points that follow.

Complex Relationships: One-to-Many and Many-to-One

A key advantage of description lists over simple JSON-like structures is their ability to handle complex associations natively without requiring nested arrays or custom logic.

One Key with Multiple Values (One-to-Many)

When a single metadata property holds multiple values, multiple <dd> elements follow a single <dt>:

<dl>
  <dt>Tags</dt>
  <dd>HTML5</dd>
  <dd>Accessibility</dd>
  <dd>Semantics</dd>
</dl>

Multiple Keys for One Value (Many-to-One)

When multiple terms share the same meaning or value, multiple <dt> elements can precede a single <dd>:

<dl>
  <dt>CSS</dt>
  <dt>Cascading Style Sheets</dt>
  <dd>A language used for describing the presentation of a document.</dd>
</dl>

Grouping with <div> for Styling

In modern web design, arranging key-value pairs horizontally using Flexbox or CSS Grid often requires a container around each pair. The HTML specification permits using standard <div> elements directly inside a <dl> to group one or more <dt> elements with one or more <dd> elements:

<dl>
  <div class="meta-row">
    <dt>Status</dt>
    <dd>Active</dd>
  </div>
  <div class="meta-row">
    <dt>Version</dt>
    <dd>2.4.1</dd>
  </div>
</dl>

This feature allows full styling flexibility without losing semantic meaning or compromising document structure.

Accessibility and Machine Readability

Using <dl>, <dt>, and <dd> offers distinct advantages over generic <div> or <span> markup:

  • Screen Readers: Modern assistive technologies announce description lists as a discrete set of terms and descriptions, enabling users to jump between terms or understand when a term has multiple values.
  • Search Engines: Web crawlers can parse description lists to interpret entity relationships, which can assist in generating rich search results and structured metadata.
  • Separation of Concerns: Semantic markup conveys the exact role of the text independently of CSS styling, ensuring the content remains meaningful in text-only browsers, reader modes, and syndication feeds.
