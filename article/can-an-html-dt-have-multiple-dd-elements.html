Can an HTML dt Have Multiple dd Elements?

Yes, an HTML <dt> (description term) element can be associated with multiple <dd> (description details) elements within a single <dl> (description list). This article explains how the HTML specification supports this one-to-many relationship, provides practical code examples, and covers best practices for accessibility and styling.

What the HTML Specification Says

According to the official W3C and WHATWG HTML specifications, a description list consists of zero or more groups of terms and descriptions. A single group can contain one or more <dt> elements followed by one or more <dd> elements.

This means that a single term can have multiple definitions, values, or explanations without violating HTML syntax or validation rules.

Basic Code Example

Here is a common scenario where a single term (a word) has multiple distinct definitions:

<dl>
  <dt>Apple</dt>
  <dd>A round fruit with red, yellow, or green skin and firm white flesh.</dd>
  <dd>An American multinational technology company headquartered in Cupertino, California.</dd>
</dl>

In this example, both <dd> elements are directly associated with the single <dt> that precedes them.

Common Use Cases

Associating multiple <dd> elements with one <dt> is useful in several scenarios:

  • Dictionary Definitions: A word that has multiple meanings or parts of speech.
  • Metadata and Properties: An author with multiple published books, or an item with multiple available colors.
  • Contact Information: A department name as the <dt>, followed by multiple <dd> tags for telephone, email, and office address.

Grouping with <div> Elements

In HTML5, you are allowed to wrap groups of <dt> and <dd> elements inside a <div> to facilitate layout and styling (such as CSS Grid or Flexbox). When using multiple <dd> elements, keep them inside the same wrapper:

<dl>
  <div class="list-group">
    <dt>Author</dt>
    <dd>Jane Doe</dd>
    <dd>John Smith</dd>
  </div>
</dl>

Accessibility and Screen Readers

Modern screen readers and assistive technologies handle multiple <dd> elements for a single <dt> well. When properly structured, screen readers inform the user of the number of items or definitions associated with the given term, preserving the semantic relationship between them.
