How JavaScript FormData Extracts Form Values

The FormData interface in JavaScript provides a streamlined way to capture and compile input fields from an HTML <form> element into a set of key-value pairs. By passing a form DOM node to the FormData constructor, JavaScript automatically traverses the form's child controls, identifies all submittable inputs, and compiles their respective names and values into an internal data structure that mirrors standard form submission.

The Construction Process

To extract data, you pass an HTML <form> element directly to the constructor:

const formElement = document.querySelector('form');
const formData = new FormData(formElement);

When invoked with a form reference, the browser executes the HTML specification's standard form-data construction algorithm. It inspects every control associated with the form and determines whether it qualifies as a submittable element.

Criteria for Extraction

For FormData to extract an input control's value, the control must meet specific standard criteria:

  1. The name Attribute: Elements must have a name attribute. If an <input>, <select>, or <textarea> lacks a name, it is completely ignored, regardless of whether it contains a value. The name becomes the key in the key-value pair.
  2. Enabled State: Disabled elements (disabled attribute present) are excluded from the extraction process.
  3. Selection State (Checkboxes and Radio Buttons): Elements of type checkbox or radio are only captured if they are in a :checked state. Unchecked options are skipped entirely.
  4. Valid Form Controls: Only standard submittable elements—<input>, <select>, <textarea>, and <button> elements (when acting as the submitter)—are processed. Generic elements like <div> or <span> are disregarded.

Handling Different Data Types

  • Text-based Inputs: Controls like <input type="text">, <textarea>, <select>, and hidden inputs map the element's name to its current string value.
  • File Inputs: An <input type="file"> does not extract a string path. Instead, FormData extracts the native File object (or objects, if the multiple attribute is present), capturing binary data, file size, and MIME type.
  • Duplicate Names: If multiple inputs share the same name (such as multi-select dropdowns or arrays of checkboxes), FormData preserves all occurrences under that single key rather than overwriting them.

Accessing the Extracted Pairs

Once initialized, the internal key-value pairs can be read and inspected using built-in methods:

  • formData.get(key): Returns the first value associated with the specified key.
  • formData.getAll(key): Returns an array of all values associated with a shared key name.
  • formData.entries(): Returns an iterator over all [key, value] pairs, allowing you to convert the data into an object or iterate using a for...of loop:
for (const [key, value] of formData.entries()) {
  console.log(`${key}:`, value);
}

// Convert directly to a plain JavaScript object
const formValues = Object.fromEntries(formData.entries());

This automatic extraction eliminates the need to manually query individual inputs and read their values, allowing forms to be processed efficiently for asynchronous HTTP requests.
