HTML s vs del: What Is the Difference?

While both the <s> and <del> HTML elements typically render text with a line through it (strikethrough) by default, they carry fundamentally different semantic meanings. The <s> tag represents content that is no longer accurate, relevant, or valid, whereas the <del> tag signifies an editorial revision where text has been explicitly removed from the document history. Choosing the correct tag ensures that web pages remain semantically accurate, accessible, and easily interpreted by search engines and assistive technologies.

The <s> Tag: Irrelevance and Inaccuracy

The <s> element indicates that the enclosed content is no longer correct, relevant, or applicable, but it does not represent an editorial change to the document.

Key characteristics of the <s> tag include:

  • Common Use Cases: Displaying original pricing alongside a discounted sale price (e.g., Was <s>$50</s>, now $35) or displaying completed items in a to-do list.
  • Scope: It addresses the status of the information itself rather than the version history of the document.
  • Accessibility: Most screen readers do not announce the presence of the <s> tag by default, meaning users relying on auditory feedback may hear the text without knowing it is struck through unless additional ARIA attributes or CSS styling techniques are applied.

The <del> Tag: Editorial Deletions

The <del> element represents an actual edit to a document—specifically, text that has been removed during a revision process. It is the semantic counterpart to the <ins> (insertion) element.

Key characteristics of the <del> tag include:

  • Common Use Cases: Displaying version history, tracking changes in legal contracts, collaborative editing platforms, or blog post corrections.
  • Semantic Attributes: It supports specialized attributes to provide context for the edit:
    • cite: A URL pointing to a document or resource that explains why the text was deleted.
    • datetime: A machine-readable timestamp indicating when the deletion occurred (e.g., datetime="2024-03-15T14:30").
  • Accessibility: Because it denotes a document change, some assistive technologies can be configured to explicitly announce text wrapped in <del> as deleted content.

Purely Visual Strikethrough

Neither <s> nor <del> should be used merely for visual styling. If strikethrough styling is needed for purely aesthetic reasons without conveying semantic irrelevance or editorial deletion, standard HTML elements such as <span> should be used in combination with the CSS text-decoration: line-through property.
