How dirname Submits Text Direction in HTML Forms

The HTML dirname attribute allows web forms to automatically determine and submit the text directionality—either left-to-right (ltr) or right-to-left (rtl)—of user input alongside the form data. By attaching a secondary query parameter to the submission payload, it informs the receiving server of the directionality chosen by the user or determined by the browser heuristics, ensuring bidirectional text renders properly when retrieved later.

What is the dirname Attribute?

The dirname attribute is an HTML5 feature used with <textarea> elements and text-based <input> elements (such as text, search, tel, url, and email). While standard inputs send their assigned name and user-provided value to the server, text directionality is not transmitted by default. Setting dirname tells the browser to create an additional submission parameter specifically dedicated to reporting the direction of the input content.

How the Browser Handles Submission

When a user submits a form containing an input with dirname, the browser performs two distinct actions:

  1. Determines Directionality: The browser evaluates the directionality of the text. This is typically determined by the first character with strong directional properties (such as Arabic or Hebrew for rtl, or Latin scripts for ltr) or the computed CSS/HTML direction of the input field if no directional characters are present.
  2. Appends Form Data: The browser includes a new key-value pair in the submission data. The key is the value assigned to the dirname attribute, and the value is either the string "ltr" or "rtl".

Example Form Markup

<form action="/submit" method="GET">
  <label for="message">Message:</label>
  <input type="text" id="message" name="message" dirname="message_dir">
  <button type="submit">Send</button>
</form>

Submission Payloads

If a user enters English text such as "Hello", the browser submits:

message=Hello&message_dir=ltr

If a user enters Arabic text such as "مرحبا", the browser automatically detects the RTL script and submits:

message=مرحبا&message_dir=rtl

Why dirname is Useful

Handling bidirectional (BiDi) text accurately requires knowing the intended reading order. Without dirname, servers must either run complex script-detection algorithms on stored strings or require users to manually select a text direction from a dropdown.

By using dirname, databases can store the reading direction alongside the content, allowing the server to output content inside the correct HTML elements with dir="ltr" or dir="rtl" attributes when redisplaying the data to users.
