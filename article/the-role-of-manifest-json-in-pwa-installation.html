The Role of manifest.json in PWA Installation

This article provides a concise overview of the role the manifest.json file plays in Progressive Web App (PWA) installation. When linked in an HTML document's <head>, this JSON-based configuration file acts as the bridge between a traditional website and a native-like application, providing the browser with the critical metadata required to enable installation prompts, configure home screen icons, and control how the app launches and displays on a user's device.

Linking the Manifest in HTML

To enable PWA functionality, the browser must first discover the manifest file. This is achieved by including a single link tag within the <head> section of the HTML document:

<link rel="manifest" href="/manifest.json">

Without this reference, modern browsers will treat the web application strictly as a standard website, entirely disabling PWA installation capabilities regardless of how the rest of the application is constructed.

Triggering the Installation Criteria

Browsers such as Google Chrome, Microsoft Edge, and Samsung Internet evaluate specific criteria before determining whether a site qualifies for PWA installation. The manifest.json file fulfills several non-negotiable requirements for triggering the browser's native "Install" button or ambient install badge:

  • Identity Definition: Fields like name and short_name define how the app is labeled on the user's home screen, application launcher, and settings menu.
  • Visual Assets: The icons array provides responsive icon paths and dimensions that the operating system uses for splash screens, desktop shortcuts, and taskbar icons.
  • Display Mode: The display property dictates whether the app opens with a standard browser UI (browser), a native-like window without an address bar (standalone), or full-screen mode (fullscreen).
  • Start Path: The start_url property ensures the application opens to a specific route rather than whichever page the user was viewing when they initiated the install.

Controlling the App Experience

Beyond merely enabling installation, manifest.json configures how the operating system renders the installed web application:

  • Theme and Background Colors: Properties such as theme_color and background_color set the color of the operating system's title bar, status bar, and initial splash screen during startup.
  • Application Scope: The scope attribute establishes the boundaries of the application. Navigating outside this defined URL scope forces the browser to open the target link in a standard browser tab rather than within the standalone PWA window.
  • App Shortcuts and Capabilities: Advanced configurations permit developers to define quick-action shortcuts (similar to long-pressing an app icon on mobile platforms), file handling rules, and protocol handlers directly within the manifest.

Conclusion

The manifest.json file referenced in the HTML <head> is the foundational requirement for PWA installation. It supplies the operating system and browser with the identity, visual assets, and launch rules necessary to convert a standard web page into an installable, standalone desktop or mobile application.
