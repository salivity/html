How to Use the HTML rel="help" Attribute

The rel="help" attribute in HTML establishes a semantic relationship between a web element or document and a dedicated help resource. This article explains how the rel="help" attribute works, how browsers and assistive technologies interpret it, how it scopes contextual assistance to specific page elements, and how to implement it correctly within your markup.

Understanding the rel="help" Attribute

The rel attribute defines the relationship between the current document and the linked resource. When assigned the value "help", it explicitly signals that the destination URL contains contextual assistance, documentation, FAQs, or explanatory text relevant to the current context. It is valid on <a>, <area>, and <link> elements.

Contextual Scoping: Page vs. Element

The primary strength of rel="help" is its contextual awareness, which depends on where the link is placed within the Document Object Model (DOM):

  1. Document-Level Help: When used within the <head> tag via a <link> element, or globally in the page header/footer, it points to help documentation for the entire web page or application.
<link rel="help" href="/support/dashboard-guide">
  1. Element-Level Help: When placed inside a parent element—such as a <form>, <fieldset>, or specific content section—the link scopes itself specifically to that container. This informs the user agent that the link provides assistance only for that specific feature or input group.
<form action="/submit-tax" method="post">
  <label for="tin">Taxpayer Identification Number (TIN):</label>
  <input type="text" id="tin" name="tin">
  <a href="/faq/tin-lookup" rel="help">Where do I find my TIN?</a>
</form>

Benefits for Accessibility and User Agents

Standard links do not communicate their intent to machines. By marking a link with rel="help", you provide structured metadata that benefits several systems:

  • Assistive Technologies: Screen readers can announce the link specifically as a help resource, allowing users with visual impairments to distinguish supplementary guidance from regular navigational links.
  • Browser Extensions and User Scripts: Browser tools can identify help links across different sites and surface them in a standardized user interface or keyboard shortcut (such as binding the F1 key to the nearest rel="help" link).
  • Search Engines: Search indexers use link relationships to better understand site architecture, mapping form guides and documentation to the pages that depend on them.

Best Practices for Implementation

  • Ensure Immediate Proximity: Place element-specific help links immediately next to the input, label, or interactive element they describe.
  • Use Clear Anchor Text: Do not rely solely on the rel="help" attribute to convey meaning to human readers; the visible anchor text should clearly describe the help being offered (e.g., use "How to find your routing number" instead of just "Help" or an isolated question mark icon).
  • Combine with Accessible Attributes: When linking help icons, ensure proper labeling using aria-label or aria-describedby alongside rel="help" for complete accessibility coverage.
