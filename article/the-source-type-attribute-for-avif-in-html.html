The Source Type Attribute for AVIF in HTML

The type attribute within a <source> element informs the web browser of an image's MIME type before any network request is initiated. When implementing modern, highly compressed formats like AVIF, this attribute enables the browser to evaluate its own format support instantly. If the format is supported, the browser fetches the file; if not, it bypasses the source entirely and falls back to a supported format, preventing broken images and wasted bandwidth.

Purpose of the type Attribute

The HTML <picture> element is designed for responsive design and progressive enhancement. Inside a <picture> tag, developers define multiple <source> elements, each pointing to different image formats or resolutions.

The type attribute explicitly states the media type using a standard MIME type string, such as image/avif or image/webp.

<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="A scenic view" width="800" height="600">
</picture>

Pre-Fetch Content Negotiation

Without the type attribute, a browser cannot determine if it supports an image file until it downloads the file headers or the entire file itself.

When the type="image/avif" attribute is present:

  1. The browser reads the <source> elements in order from top to bottom.
  2. It checks its internal capabilities against the MIME type specified in type.
  3. If the browser lacks native AVIF decoding, it immediately ignores the <source> without sending an HTTP request.
  4. It moves to the next candidate (such as WebP) and finally defaults to the standard <img> fallback (such as JPEG or PNG).

Performance Implications

AVIF provides significantly superior compression compared to legacy formats, often reducing file sizes by up to 50% compared to JPEG and 20% compared to WebP at similar visual quality. However, older browsers and certain embedded web views do not support AVIF.

Using the type attribute guarantees that modern image compression benefits supported clients without penalizing older clients with failed downloads, redundant network traffic, or blank image placeholders. This makes the type attribute the foundational mechanism for safe, backward-compatible image optimization on the modern web.
