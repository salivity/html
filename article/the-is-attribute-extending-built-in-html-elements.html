The is Attribute: Extending Built-in HTML Elements

The is attribute in HTML allows developers to instantiate "customized built-in elements," extending standard native tags like <button>, <input>, or <form> with custom JavaScript behaviors. Instead of building custom components entirely from scratch, using is applies custom element logic to an existing HTML element while preserving its native semantics, accessibility features, and built-in interactive behaviors.

Autonomous vs. Customized Built-in Elements

The Web Components specification defines two distinct types of custom elements:

  1. Autonomous Custom Elements: Independent HTML elements created by extending the generic HTMLElement interface (e.g., <user-card></user-card>). They possess no implicit semantics, styles, or behaviors.
  2. Customized Built-in Elements: Elements that inherit from a specific native interface, such as HTMLButtonElement or HTMLInputElement. These are rendered using the standard HTML tag paired with the is attribute (e.g., <button is="action-button">Submit</button>).

Preserving Accessibility and Native Semantics

The primary significance of the is attribute is the automatic retention of built-in browser features. Building an autonomous custom element to replace a standard element requires manually implementing keyboard navigation, focus management, state tracking, and appropriate ARIA roles.

By contrast, an element using the is attribute inherits all existing behaviors of the underlying native element. For example, a <button is="custom-button"> automatically supports the Enter and Space keys for activation, naturally receives tab focus, integrates natively with HTML <form> submissions, and is identified correctly by screen readers without additional accessibility work.

How the is Attribute Works

To extend a built-in element, you must define a class that extends the appropriate element subclass, specify the target tag in the registry options, and reference the custom name in your markup.

In JavaScript:

class ExpandableList extends HTMLUListElement {
  connectedCallback() {
    this.addEventListener('click', this.toggleExpand);
  }

  toggleExpand() {
    this.classList.toggle('expanded');
  }
}

customElements.define('expandable-list', ExpandableList, { extends: 'ul' });

In HTML:

<ul is="expandable-list">
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

You can also instantiate the element programmatically using document.createElement('ul', { is: 'expandable-list' }).

Progressive Enhancement

The is attribute is ideal for progressive enhancement. If a browser does not execute JavaScript or fails to load custom component scripts, the page still renders a functioning native HTML element rather than an empty or unstyled custom tag. A customized link (<a is="router-link" href="/page">) will still function as a standard hyperlink even if the single-page application router logic fails to initialize.

Implementation Considerations

While the is attribute provides significant semantic and accessibility advantages, developers should note that Apple's WebKit engine (Safari) has declined to implement customized built-in elements natively. In projects targeting Safari, utilizing customized built-in elements with the is attribute generally requires a lightweight polyfill to ensure consistent behavior across all modern browsers.
