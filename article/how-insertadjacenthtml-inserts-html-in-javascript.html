How insertAdjacentHTML Inserts HTML in JavaScript

The insertAdjacentHTML() method in JavaScript parses a specified text as HTML or XML and inserts the resulting nodes into the DOM tree at a specified position relative to a target element. Unlike modifying innerHTML, this method does not reparse the target element's existing contents, making it significantly faster and preventing the destruction of existing event listeners inside that element.

Syntax

element.insertAdjacentHTML(position, text);

The method accepts two arguments:

  • position: A string determining where to place the new HTML relative to the target element.
  • text: The string representing valid HTML or XML markup to be parsed and inserted.

The Four Position Values

The behavior of insertAdjacentHTML() relies entirely on one of four case-insensitive position keywords:

<!-- 'beforebegin' -->
<div id="target">
  <!-- 'afterbegin' -->
  <p>Existing Child Content</p>
  <!-- 'beforeend' -->
</div>
<!-- 'afterend' -->

1. 'beforebegin'

Inserts the HTML immediately before the target element itself, as a sibling. This only works if the target element is inside a DOM tree and has a parent element.

const target = document.getElementById('target');
target.insertAdjacentHTML('beforebegin', '<p>Inserted before the target</p>');

2. 'afterbegin'

Inserts the HTML inside the target element, right before its first child node.

target.insertAdjacentHTML('afterbegin', '<p>Inserted inside, at the top</p>');

3. 'beforeend'

Inserts the HTML inside the target element, right after its last child node. This functions similarly to appendChild(), but accepts a raw markup string instead of a DOM Node object.

target.insertAdjacentHTML('beforeend', '<p>Inserted inside, at the bottom</p>');

4. 'afterend'

Inserts the HTML immediately after the target element itself, as a sibling. Like 'beforebegin', this requires the target element to have a parent node.

target.insertAdjacentHTML('afterend', '<p>Inserted after the target</p>');

Key Benefits Over innerHTML

  • Preserves Existing DOM Nodes: Setting element.innerHTML += markup destroys all existing child nodes, recreates them from scratch, and breaks any attached event handlers. insertAdjacentHTML() only creates and attaches the new elements.
  • Better Performance: Because it avoids re-serializing and re-parsing the existing DOM tree, it executes considerably faster when appending or prepending content.

Security Considerations

When using insertAdjacentHTML(), never pass unsanitized user-provided input directly into the text parameter. Directly injecting untrusted data creates a cross-site scripting (XSS) vulnerability. Always sanitize HTML inputs or use text-based DOM methods like textContent when dealing with plain text.
