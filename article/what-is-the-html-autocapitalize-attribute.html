What Is the HTML autocapitalize Attribute?

The autocapitalize attribute is an HTML attribute that controls how mobile and virtual keyboards automatically capitalize letters as a user types into form fields. By defining the capitalization behavior directly in the markup, developers can tailor text entry to specific types of data, streamlining the mobile user experience and preventing input errors in fields like usernames, URLs, or personal names.

The Purpose of autocapitalize

Mobile operating systems such as iOS and Android typically default to capitalizing the first letter of a text input. While this behavior is ideal for standard paragraphs or messages, it introduces unnecessary friction when users enter email addresses, usernames, coupon codes, or computer code.

The autocapitalize attribute communicates with the device's virtual keyboard, instructing it when—and if—to activate the Shift key automatically. It is important to note that this attribute only affects virtual keyboards; it does not alter input from physical keyboards, nor does it visually transform text after it has been typed like CSS text-transform does.

Supported Values

The autocapitalize attribute accepts five standard values to cover various input scenarios:

  • none (or off): Disables automatic capitalization completely. Every character defaults to lowercase unless the user manually shifts the keyboard. This is essential for usernames, handles, and programming fields.
  • sentences (or on): The default behavior for standard text inputs. The keyboard automatically capitalizes the first letter of each sentence.
  • words: Capitalizes the first letter of every word. This value is best used for fields requiring proper nouns, such as full names, street addresses, or product titles.
  • characters: Forces every letter to be capitalized (caps lock behavior). This is ideal for inputs like state abbreviations, postal codes, license plates, or airport codes.

Usage and Scope

The attribute can be used directly on <input> and <textarea> elements:

<!-- Disabling capitalization for a username -->
<input type="text" name="username" autocapitalize="none">

<!-- Capitalizing each word for a full name -->
<input type="text" name="fullname" autocapitalize="words">

<!-- Capitalizing all letters for a promo code -->
<input type="text" name="promo" autocapitalize="characters">

Beyond individual inputs, autocapitalize can also be applied to:

  • <form> elements: Setting the attribute on a form sets the default capitalization behavior for all descendant inputs, though individual inputs can still override it.
  • contenteditable elements: Any custom editable container can utilize the attribute to dictate virtual keyboard input.

Interactions with Input Types

Modern browsers automatically disable capitalization for specific input types, such as type="email", type="password", and type="url". However, standard type="text" fields do not receive these automatic protections. Using autocapitalize ensures that standard text fields behave appropriately according to the intended data type, significantly improving mobile form usability.
