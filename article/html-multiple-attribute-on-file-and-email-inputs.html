HTML Multiple Attribute on File and Email Inputs

The multiple attribute in HTML is a boolean attribute that permits users to enter or select more than one value in a single form control. When applied to <input type="file">, it allows users to choose multiple files simultaneously from their device's file picker. When applied to <input type="email">, it enables users to submit a comma-separated list of valid email addresses within a single field. This guide explains how the attribute functions on both input types, how browsers handle them, and what is required for proper implementation.

The multiple Attribute on File Inputs

By default, an <input type="file"> element permits the selection of only one file at a time. Adding the multiple attribute changes this behavior:

<label for="documents">Upload files:</label>
<input type="file" id="documents" name="documents" multiple>

How It Works

  • User Interaction: When the file picker dialog opens, users can hold Shift or Ctrl (or Cmd on macOS) to select multiple files in a single operation.
  • Mobile Support: On mobile browsers, users can typically tap multiple photos, videos, or documents within their system file viewer.
  • JavaScript Access: In the DOM, the input's files property returns a FileList object containing all selected File objects. Developers can iterate through this list to inspect file names, sizes, types, or upload them via the Fetch API using FormData.
  • Backend Processing: Backends must be configured to accept an array of files rather than a single file object, often requiring array notation in the input's name attribute (e.g., name="documents[]") depending on the server-side language.

The multiple Attribute on Email Inputs

When applied to <input type="email">, the multiple attribute alters standard email validation to allow multiple recipient addresses:

<label for="recipients">Invite team members:</label>
<input type="email" id="recipients" name="recipients" multiple>

How It Works

  • Syntax Requirements: Users must separate individual email addresses with commas (e.g., user1@example.com, user2@example.com).
  • Whitespace Handling: Leading and trailing whitespace around each comma-separated address is automatically trimmed by the browser during parsing.
  • Built-in Validation: HTML5 form validation checks every listed address against the standard email regex format. If any single address in the sequence is invalid, the entire input fails validation and prevents form submission.

Key Considerations

  • Boolean Nature: Because multiple is a boolean attribute, its presence alone activates the functionality. Writing multiple, multiple="multiple", or multiple="" all have the exact same effect.
  • Applicability: The multiple attribute is only valid on <input type="file">, <input type="email">, and <select> elements. Applying it to other input types, such as text or password, has no effect.
  • User Guidance: While browsers handle validation natively, visual cues such as helper text or placeholder examples (e.g., placeholder="name1@example.com, name2@example.com") should be provided so users know multiple inputs are permitted.
