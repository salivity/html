HTML Size Attribute on Input and Select Explained

The HTML size attribute controls the visible physical dimensions of form controls, specifically the <input> and <select> elements. While its core purpose is visual presentation, it functions differently depending on the element it is applied to: setting the visible character width for text-based inputs, and setting the number of visible rows for selection menus. Understanding how this attribute works ensures better form design and accessibility, while clarifying when to use HTML attributes versus modern CSS for layout.

The size Attribute on the <input> Element

On an <input> element, the size attribute defines the visible width of the control in terms of average character width.

  • Applicable Types: It primarily applies to text-oriented input types, including text, search, tel, url, email, and password.
  • Value: The value must be an integer greater than zero. For example, <input type="text" size="20"> creates an input field sized to comfortably display approximately 20 characters.
  • Important Distinction: The size attribute does not restrict the number of characters a user can enter. To limit user input length, use the maxlength attribute instead.
  • Modern Usage: In responsive web design, setting widths using CSS properties like width, max-width, or ch units is generally preferred over the HTML size attribute, as CSS allows for fluid scaling across different screen sizes.

The size Attribute on the <select> Element

On a <select> element, the size attribute defines how many options are visible to the user at the same time.

  • Default Behavior: By default, a <select> element has a size of 1, rendering it as a standard single-line drop-down menu that opens when clicked.
  • List Box Transformation: When the size attribute is set to an integer greater than 1 (such as <select size="5">), the browser transforms the drop-down menu into a scrollable list box displaying that specified number of options simultaneously.
  • Interaction with the multiple Attribute: When the multiple attribute is present on a <select> tag without an explicit size, browsers typically default the visible size to 4 rows. Setting an explicit size overrides this default.

Key Differences Summary

Feature <input> Element <select> Element
Measurement Unit Average character width Number of visible rows/options
Default Value Browser-dependent (usually 20) 1 (or 4 if multiple is active)
Structural Effect Changes the horizontal width Changes the interface from a drop-down to a list box
