HTML Dialog returnValue Property with Forms

The native HTML <dialog> element provides a built-in mechanism for managing modals and popups, featuring a property called returnValue. When a dialog is dismissed using an embedded <form method="dialog">, the returnValue property captures the value of the submit button that was clicked, enabling developers to easily determine the user's choice without requiring custom state management or event listeners on every button.

How method="dialog" Works

When a <form> element has its method attribute set to "dialog", submitting the form does not send an HTTP request or refresh the page. Instead, the submission intercepts the event and closes the parent <dialog> element automatically.

The Role of returnValue

The primary function of returnValue is to store a string that indicates the outcome of the dialog interaction. When a form with method="dialog" is submitted, the browser sets the dialog’s returnValue property to the value attribute of the submit button that triggered the submission.

If the user submits the form using an input or a button without a value attribute, or by pressing Enter in a text field, the returnValue is typically set to an empty string ("").

Example Implementation

<dialog id="confirmDialog">
  <form method="dialog">
    <p>Do you want to save your changes?</p>
    <button type="submit" value="cancel">Cancel</button>
    <button type="submit" value="confirm">Save</button>
  </form>
</dialog>

<script>
  const dialog = document.getElementById('confirmDialog');

  dialog.addEventListener('close', () => {
    if (dialog.returnValue === 'confirm') {
      console.log('User chose to save changes.');
    } else if (dialog.returnValue === 'cancel') {
      console.log('User cancelled the action.');
    }
  });
</script>

Key Behaviors and Characteristics

  • Captured on the close Event: The updated returnValue is available immediately inside the dialog's close event listener.
  • String Type: The returnValue property always returns a string, even if the value provided is numeric.
  • Alternative to dialog.close(value): While calling the JavaScript method dialog.close("customValue") achieves the same result, <form method="dialog"> allows this behavior to be handled entirely via semantic HTML.
  • State Persistence: The returnValue persists after the dialog is closed until the dialog is reopened and closed again with a new value, or until manually modified via script (dialog.returnValue = '').
