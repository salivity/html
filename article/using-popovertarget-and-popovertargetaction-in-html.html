Using Popovertarget and Popovertargetaction in HTML

The HTML Popover API provides a native, JavaScript-free way to display floating content like tooltips, menus, and dialogs directly in the browser's top layer. This article explains how the popovertarget and popovertargetaction attributes work together on button elements to open, close, and toggle popover elements declaratively using pure HTML.

The Foundation: The Popover Element

Before using target attributes, you must define the popover element itself. Adding the popover attribute to any HTML element (commonly a <div>) instructs the browser to hide the element by default, remove it from standard page flow, and render it in the top layer when activated. To connect a trigger to this element, assign it a unique id.

<div id="my-popover" popover>
  <p>This is native popover content.</p>
</div>

The popovertarget Attribute

The popovertarget attribute connects an invoking control—typically a <button> or <input type="button">—to the target popover.

Its value must match the id of the element containing the popover attribute. By default, clicking a button with a valid popovertarget will toggle the visibility of the linked popover without requiring an addEventListener script.

<!-- Clicking this toggles the visibility of #my-popover -->
<button popovertarget="my-popover">Toggle Popover</button>

The popovertargetaction Attribute

While popovertarget specifies which element to control, popovertargetaction specifies what action the button should perform.

The popovertargetaction attribute accepts three values:

  • toggle: The default behavior. If the popover is hidden, the button opens it; if it is visible, the button closes it.
  • show: Exclusively opens the popover. If the popover is already open, clicking the button does nothing.
  • hide: Exclusively closes the popover. This is most commonly placed on a "Close" button located inside the popover itself.
<!-- Explicit show button -->
<button popovertarget="info-box" popovertargetaction="show">
  Open Info
</button>

<div id="info-box" popover>
  <p>Detailed information goes here.</p>
  
  <!-- Explicit close button inside the popover -->
  <button popovertarget="info-box" popovertargetaction="hide">
    Close
  </button>
</div>

Native Benefits and Behaviors

Pairing popovertarget and popovertargetaction provides several built-in browser features automatically:

  • Focus Management and Keyboard Support: Pressing the Escape key automatically closes an active popover.
  • Light Dismiss: When using the default popover="auto" mode, clicking outside the popover automatically closes it and updates internal state tracking.
  • Top Layer Stacking: Popovers controlled by these attributes are placed in the browser's top layer, preventing z-index conflicts and overflow clipping from parent elements.
  • Accessibility: Browsers automatically expose the relationship between the trigger button and the popover element to assistive technologies without requiring manual ARIA expanded states.
