Dynamic theme-color Meta Tag for Dark and Light Mode

The HTML theme-color meta tag customizes the accent color of the browser's surrounding interface, such as the address bar, status bar, or tab bar. By pairing the media attribute with the prefers-color-scheme CSS media query, developers can define separate theme colors for light and dark modes. This setup allows the browser UI to adapt automatically to a user's system preferences in real time without relying on JavaScript.

The HTML Implementation

To adapt the theme-color meta tag dynamically, define multiple <meta name="theme-color"> tags within the <head> of your document, each with a corresponding media attribute:

<!-- Theme color for light mode -->
<meta name="theme-color" content="#ffffff" media="(prefers-color-scheme: light)">

<!-- Theme color for dark mode -->
<meta name="theme-color" content="#121212" media="(prefers-color-scheme: dark)">

How the Browser Handles the Adaptation

  1. System Preference Detection: Modern operating systems (like macOS, Windows, iOS, and Android) allow users to choose between a light and dark system interface. Browsers detect this choice and expose it through the prefers-color-scheme media feature.
  2. Media Query Evaluation: When the browser parses the <head>, it evaluates the media attribute on each theme-color meta tag just as it would with an external stylesheet link.
  3. Dynamic Switching: If a user switches their device from light mode to dark mode (or vice versa), the browser re-evaluates the media query immediately. It changes the UI chrome color to match the newly active content value with no page refresh required.

Fallback Strategies

Not all user agents or older browser versions support the media attribute on <meta> elements. To ensure broader compatibility, declare a default theme-color without a media attribute, followed by the specific media query definitions:

<!-- Base fallback for older browsers -->
<meta name="theme-color" content="#ffffff">

<!-- Dynamic overrides based on preference -->
<meta name="theme-color" content="#ffffff" media="(prefers-color-scheme: light)">
<meta name="theme-color" content="#121212" media="(prefers-color-scheme: dark)">

Browsers that recognize the media attribute will prioritize the matching query, while older browsers will default to the standard fallback tag.

Browser Support

This declarative approach is supported in modern versions of Google Chrome (Android and desktop PWA windows), Apple Safari (iOS and macOS), and other Chromium-based browsers. It requires no runtime JavaScript overhead, reducing execution time and preventing color flashes during initial page render.
