HTMLCollection vs NodeList: What Is the Difference?

When querying the Document Object Model (DOM) in JavaScript, methods return groups of nodes typically structured as either an HTMLCollection or a NodeList. While both are array-like objects used to store multiple DOM elements, they differ critically in the types of nodes they hold, whether they dynamically reflect changes in the DOM (liveness), and the built-in array methods they support.

1. Types of Nodes Contained

  • HTMLCollection: Contains only element nodes (Element). It ignores non-element nodes such as text nodes, whitespace, and comment nodes.
  • NodeList: Can contain any node type. Depending on how it was generated, it can include element nodes, text nodes, comment nodes, and document fragments.

2. Live vs. Static Collections

  • HTMLCollection is always live: If the DOM changes—such as an element being added, updated, or removed via JavaScript—the HTMLCollection automatically updates its contents and length in real time.
  • NodeList is mostly static: A NodeList returned by modern querying methods like document.querySelectorAll() is static. It represents a snapshot of the DOM at the exact moment the query was executed. If the DOM changes later, the static NodeList does not change.
    • Exception: The Node.childNodes property returns a live NodeList.

3. Retrieval Methods

Different DOM querying methods return different object types:

Methods returning an HTMLCollection:

  • document.getElementsByTagName()
  • document.getElementsByClassName()
  • element.children

Methods returning a NodeList:

  • document.querySelectorAll() (Static)
  • element.childNodes (Live)

4. Available Methods and Iteration

Neither interface is a full JavaScript Array, meaning standard array methods like .map(), .filter(), or .reduce() cannot be used directly without conversion (e.g., using Array.from() or the spread operator [...]). However, their built-in iteration options differ:

  • HTMLCollection:
    • Access items by numeric index (collection[0]) or by name/ID using the namedItem() method.
    • Does not support forEach() natively. To loop through it, use a standard for loop, a for...of loop, or convert it to an array.
  • NodeList:
    • Access items by numeric index (list[0]).
    • Supports the native .forEach() method directly, allowing iteration without prior conversion.

Summary Comparison

Feature HTMLCollection NodeList
Node Types Elements only Any node type (elements, text, comments)
Liveness Always live Mostly static (querySelectorAll), rarely live (childNodes)
Native forEach No Yes
Named Access Yes (namedItem() or named properties) No
Common Source getElementsByClassName, children querySelectorAll, childNodes
