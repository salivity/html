How Noindex Nofollow Meta Tag Works

The <meta name="robots" content="noindex, nofollow"> HTML directive is an instruction that controls how search engines crawl, index, and evaluate a specific webpage. This article explains the technical definition of the tag, breaks down the combined impact of the "noindex" and "nofollow" directives on search engine crawlers, outlines the proper implementation method, and highlights critical considerations to ensure search engines respect these rules.

Technical Breakdown of the Tag

The directive is placed within the <head> section of an HTML document:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta name="robots" content="noindex, nofollow">
    <title>Example Page</title>
</head>
<body>
    ...
</body>
</html>

The tag consists of three primary components:

  • name="robots": Directs the instruction to all standard web search crawlers (such as Googlebot or Bingbot). Specific bot names, such as googlebot, can be substituted to target a single crawler.
  • noindex: Instructs search engines not to display the page in search engine results pages (SERPs). If the page is currently in the search index, search engines will remove it after recrawling and processing the directive.
  • nofollow: Instructs search engines not to crawl any hyperlinks present on the page and not to pass search authority (link equity or PageRank) to the destination URLs.

How Search Engines Process the Directive

When a search engine spider visits a page containing this tag, it executes the following steps:

  1. Crawler Access: The bot downloads the HTML content of the page.
  2. Parsing the <head>: The bot reads the metadata before rendering or indexing the document.
  3. Execution of noindex: The bot tags the URL to be excluded from its search index database. The content, title, and snippets will not appear in search results.
  4. Execution of nofollow: The bot ignores all anchor tags (<a>) on the page for discovery and link evaluation purposes. It will not follow these links to discover new URLs, nor will it pass ranking signals to linked pages.

Key Distinctions and Technical Nuances

Difference Between robots.txt and Meta Robots

A common error is disallowing a page in the robots.txt file while applying a noindex meta tag. For a search engine to read and obey the noindex, nofollow directive, it must be allowed to crawl the page. If a page is blocked via robots.txt, the crawler cannot fetch the HTML, cannot see the meta tag, and may still index the bare URL if other sites link to it.

Meta Tag vs. X-Robots-Tag

The <meta name="robots"> tag only functions within HTML documents. For non-HTML files, such as PDFs, images, or documents, the equivalent instruction must be served via the HTTP header using the X-Robots-Tag:

X-Robots-Tag: noindex, nofollow

Long-Term Treatment of Noindex

Major search engines like Google treat a long-standing noindex directive similarly to a nofollow over time. If a page remains noindex for an extended period, crawlers eventually stop visiting the page frequently and will stop following its links entirely, even if only noindex (without nofollow) was originally specified. Specifying both explicitly ensures immediate exclusion and non-crawl behavior.

Common Use Cases

The combined noindex, nofollow directive is typically applied to:

  • Staging, testing, or development environments that should remain private from search engines.
  • Internal administrative portals and login screens.
  • Order confirmation, shopping cart, and "thank you" pages generated during user transactions.
  • Thin, duplicate, or internal search result pages that provide no organic search value.
  • Privacy Policy
  • Terms and Conditions
