HTML Description Lists for Glossaries and Metadata

The HTML description list element (<dl>) provides a semantic framework for presenting paired data, making it an ideal choice for online glossaries, key-value metadata, and technical specifications. This article explains the architectural role of the <dl>, <dt>, and <dd> tags, how they establish clear relationships between terms and definitions, and how to effectively leverage them to improve document accessibility and search engine readability.

The Semantic Structure of <dl>

A description list consists of an enclosing <dl> tag populated by at least one pair of <dt> (description term) and <dd> (description details) tags:

  • <dl> (Description List): Acts as the parent container that establishes the context for associated pairs.
  • <dt> (Description Term): Identifies the name, key, or term being described.
  • <dd> (Description Details): Supplies the value, definition, or explanation corresponding to the term.

HTML allows flexible relationships within a single list. A single <dt> can be followed by multiple <dd> tags (useful when a word has multiple definitions), and multiple <dt> tags can precede a single <dd> (useful when synonyms share the same meaning). Additionally, HTML permits wrapping each <dt>/<dd> pair inside a <div> element strictly for CSS styling and layout purposes without breaking semantics.

Structuring Glossaries

For glossaries, dictionaries, and FAQ sections, the description list maps directly to natural language conventions:

<dl>
  <dt>API</dt>
  <dd>Application Programming Interface, a set of protocols and tools for building software applications.</dd>

  <dt>DOM</dt>
  <dd>Document Object Model, a programming interface for web documents representing the structure of a page as a tree.</dd>
</dl>

Using <dl> for a glossary informs assistive technologies, such as screen readers, that the content represents an association between terms and definitions rather than a generic linear sequence of text. Screen readers can announce the total number of terms and allow users to jump directly between terms and definitions.

Structuring Metadata

The <dl> element is also standard for key-value pairs representing item metadata, such as product specifications, article attributes, or configuration settings:

<dl>
  <div>
    <dt>Author</dt>
    <dd>Jane Doe</dd>
  </div>
  <div>
    <dt>Published Date</dt>
    <dd><time datetime="2024-03-15">March 15, 2024</time></dd>
  </div>
  <div>
    <dt>License</dt>
    <dd>MIT</dd>
  </div>
</dl>

Using <dl> for metadata is semantically superior to using generic <div> tags or an unordered list (<ul>). While <ul> simply implies an arbitrary set of items, <dl> explicitly denotes that the key (<dt>) and value (<dd>) are intrinsically linked. This structural clarity aids search engines in parsing structured data and extracting relationships between entities.
