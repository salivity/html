How Cumulative Layout Shift Measures Visual Instability

This article explains how Cumulative Layout Shift (CLS) quantifies unexpected visual movement caused by dynamically loaded HTML elements. Readers will learn the exact mathematical formula browsers use—multiplying the impact fraction by the distance fraction—as well as how session windows aggregate these shifts, how user interactions are accounted for, and why unreserved space for dynamic content triggers high CLS scores.

The Mechanism Behind Layout Shifts

When a browser renders a webpage, it calculates the position and dimensions of every Document Object Model (DOM) element in the visual viewport. A layout shift occurs whenever a visible element changes its start position (its top-left coordinates in the layout grid) between two rendered frames without direct user interaction.

Dynamically loaded HTML elements—such as client-side rendered components, asynchronously injected advertisements, late-loading web fonts, or images without explicit dimension attributes—are the primary culprits. When these elements enter the DOM after initial layout calculations, they displace already rendered content downward or sideways, causing visual instability.

The Layout Shift Score Formula

To quantify this instability, the browser calculates a Layout Shift Score for every unexpected shift event using two metrics: the Impact Fraction and the Distance Fraction.

Layout Shift Score = Impact Fraction × Distance Fraction

1. The Impact Fraction

The impact fraction measures how unstable elements impact the viewport area between two frames.

To determine this value:

  • The browser calculates the union of the visible bounding boxes of all unstable elements before the shift and after the shift.
  • It then divides this combined area by the total area of the visible viewport.

For example, if an asynchronously loaded banner pushes content down so that the affected elements occupied 50% of the viewport prior to the shift and now occupy 50% in their new position, with a total combined area covering 75% of the viewport, the impact fraction is 0.75.

2. The Distance Fraction

The distance fraction measures the greatest distance any single unstable element moved relative to the viewport's largest dimension (either width or height).

  • If an element shifts vertically by 150 pixels on a viewport that is 1000 pixels high, the greatest movement distance is 150 pixels.
  • The distance fraction is 150 / 1000 = 0.15.

Multiplying these two fractions yields the shift score for that single event:

0.75 (Impact Fraction) × 0.15 (Distance Fraction) = 0.1125

Session Windows and Cumulative Aggregation

Rather than summing every shift linearly across an entire page lifecycle, modern implementations of CLS group layout shifts into session windows.

  • A session window contains one or more layout shifts that occur in rapid succession.
  • A window opens with the first layout shift and continues until there is a gap of at least 1 second between shifts.
  • A session window has a maximum total duration cap of 5 seconds.

The overall CLS score of a page represents the maximum session window score—the highest combined score of any single window observed during the page visit. This approach ensures that pages with long lifespans (like Single Page Applications) are not unfairly penalized for isolated, spread-out shifts while still heavily penalizing rapid bursts of instability caused by dynamic rendering.

Expected vs. Unexpected Shifts

CLS exclusively quantifies unexpected movement. Layout shifts that occur within 500 milliseconds of an explicit user interaction—such as a tap, click, or keystroke—are flagged with a hadRecentInput boolean.

The browser excludes these shifts from the CLS calculation under the assumption that the layout update was an expected response to user intent (such as expanding an accordion menu or submitting a form). However, dynamic elements loaded via asynchronous network requests triggered by a user action often exceed the 500ms window, resulting in penalized shifts unless layout dimensions are reserved in advance.
