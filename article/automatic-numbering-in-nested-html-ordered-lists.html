Automatic Numbering in Nested HTML Ordered Lists

By default, native HTML ordered lists (<ol>) restart their numbering at 1 at each nested sub-level rather than generating compound numbering such as 1.1, 1.2, or 1.2.1. While HTML structural tags create the list hierarchy, achieving true automatic numerical nesting requires CSS counter functions. This article covers the default behavior of nested HTML lists and details how to implement fully automatic hierarchical numerical formatting using CSS.

Default HTML Behavior

When you nest an <ol> inside an <li>, HTML creates an independent list context. The browser resets the counter for the inner list back to 1.

<ol>
  <li>First item
    <ol>
      <li>First sub-item (displays as 1, not 1.1)</li>
      <li>Second sub-item (displays as 2, not 1.2)</li>
    </ol>
  </li>
  <li>Second item</li>
</ol>

HTML does provide a type attribute (1, a, A, i, I) to change numbering styles between numbers, letters, and Roman numerals. However, it provides no native mechanism to concatenate parent list numbers with child list numbers.

Enabling Compound Numbering with CSS Counters

To automatically format numbers across nested levels (e.g., 1, 1.1, 1.1.1), you must disable standard list markers and use CSS counters.

The CSS Implementation

ol {
  counter-reset: section;
  list-style-type: none;
  padding-left: 1.5rem;
}

li {
  counter-increment: section;
}

li::before {
  content: counters(section, ".") " ";
  font-weight: bold;
}

How It Works

  1. list-style-type: none; removes the default browser markers (numbers or bullets) from the <ol> elements so they do not conflict with custom numbers.
  2. counter-reset: section; creates a new counter instance called section on every <ol> element. Each nested <ol> initiates its own scoped counter instance.
  3. counter-increment: section; increments the active section counter every time a new <li> element is rendered.
  4. content: counters(section, ".") " "; uses the counters() function (plural), which evaluates all nested instances of the section counter in the DOM tree and joins them using the specified separator string (in this case, ".").

Example Output

Using the CSS rules above, the following markup:

<ol>
  <li>Introduction
    <ol>
      <li>Background</li>
      <li>Objectives</li>
    </ol>
  </li>
  <li>Methodology
    <ol>
      <li>Data Collection
        <ol>
          <li>Surveys</li>
          <li>Interviews</li>
        </ol>
      </li>
    </ol>
  </li>
</ol>

Renders automatically formatted as:

  • 1 Introduction
    • 1.1 Background
    • 1.2 Objectives
  • 2 Methodology
    • 2.1 Data Collection
      • 2.1.1 Surveys
      • 2.1.2 Interviews

This approach functions across arbitrary nesting depths without requiring extra classes or inline styles.
