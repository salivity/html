HTML Input Types: The Complete Guide

The HTML <input> element is one of the most versatile elements in web development, relying on its type attribute to define what kind of data it accepts and how it behaves. This guide outlines the various data types supported by the HTML <input> element, explaining how each input type functions, handles user data, and facilitates built-in browser validation.

Text-Based Data Types

  • text: The default input type. It creates a basic single-line text field for general alphanumeric data.
  • password: Obscures entered characters (using dots or asterisks) to protect sensitive data like credentials.
  • email: Accepts email addresses. It includes automatic validation to ensure proper formatting (e.g., presence of an @ symbol) and triggers email-optimized keyboards on mobile devices.
  • url: Designed for web addresses. It validates that the input is a properly structured URL (beginning with protocols like http:// or https://).
  • tel: Used for telephone numbers. Unlike email or url, it does not enforce a specific format automatically due to varied international formats, but it triggers a telephone keypad on mobile screens.
  • search: Styled specifically for search queries, often including a quick-clear icon natively provided by the browser.

Numeric and Value Range Types

  • number: Restricts input to numerical values. It supports attributes such as min, max, and step to define acceptable numeric boundaries, and typically provides up/down spinner buttons.
  • range: Renders a slider control for selecting an approximate numerical value within a defined range using min, max, and step attributes.

Date and Time Types

  • date: Provides an interface (often a calendar dropdown) for selecting a year, month, and day without a time zone.
  • datetime-local: Allows users to select both a date and a time (hours and minutes) without specifying a time zone.
  • time: Allows entry of a specific time value (hours, minutes, and optionally seconds) with no date associated.
  • month: Enables selection of a specific month and year.
  • week: Enables selection of a specific week and year.

Choice and Selection Types

  • checkbox: Represents a binary choice (checked or unchecked). Multiple checkboxes in a form can be selected simultaneously.
  • radio: Represents a single choice among a group of mutually exclusive options sharing the same name attribute.

File and Media Types

  • file: Enables users to select and upload one or more files from their local storage device. It can be paired with the accept attribute to limit specific file formats.
  • color: Displays a graphical color picker interface that outputs the selected color as a six-digit hexadecimal string (e.g., #ff0000).

Action and Form Control Types

  • submit: Renders a button that sends the form data to the specified action handler.
  • reset: Renders a button that resets all fields in the parent form to their default values.
  • button: A general push button with no default behavior, primarily used to trigger JavaScript events.
  • image: Displays a graphical submit button using an image specified by the src attribute. It also transmits the coordinate clicks of the user.
  • hidden: Stores data that must be submitted with the form but should not be visible or editable by the user directly on the page.
