Formatting Math Variables with the HTML Var Tag

The HTML <var> element represents a variable in mathematical expressions or programming contexts within academic and technical documents. By default, web browsers format the contents of a <var> tag in italics, aligning with international typographic standards for mathematical notation. Beyond basic visual styling, the tag serves a critical semantic role in academic HTML publishing by distinguishing mathematical symbols from general emphasized text, improving accessibility for assistive technologies, and providing structured hooks for custom typographic styling.

Default Browser Rendering and Typographic Conventions

In standard user-agent stylesheets, the <var> element is assigned a single primary rule: font-style: italic. This default behavior directly mirrors standard academic publishing conventions—such as those defined by ISO 80000-2 and the American Mathematical Society (AMS)—which dictate that single-letter variables representing scalar quantities (such as \(x\), \(y\), or \(n\)) must be rendered in sloping type. Because <var> is an inline element, it flows seamlessly within running text, allowing expressions like <var>E</var> = <var>m</var><var>c</var><sup>2</sup> to match the surrounding paragraph height and baseline.

Semantic Differentiation in Academic Markup

Unlike the <i> (idiomatic text) or <em> (stress emphasis) elements, <var> carries explicit machine-readable meaning. In peer-reviewed journals, digital textbooks, and preprint servers, semantic distinction is vital for:

  • Screen Readers and Accessibility: Specialized text-to-speech engines can announce the content of <var> tags explicitly as variables rather than reading them with vocal emphasis or treating them as foreign terms.
  • Text Mining and Indexing: Search engines and academic parsers can isolate mathematical variables from narrative text, facilitating automated formula indexing, knowledge graph construction, and cross-referencing.
  • Targeted CSS Styling: Academic publishers can style all mathematical entities globally without inadvertently altering italicized book titles, foreign phrases, or emphasized prose.

Advanced Formatting and CSS Integration

While default italics suffice for basic inline variables, academic publications often require rigorous typographical adjustments to replicate traditional print mathematics. Publishers typically target the <var> tag with custom CSS to control font families, metrics, and case-specific variants:

  • Math-Specific Typefaces: CSS rules commonly apply dedicated fonts such as Computer Modern, Latin Modern Math, STIX Two Text, or Times New Roman to <var> elements: 
    var {
  font-family: "STIX Two Math", "Latin Modern Math", "Times New Roman", serif;
  font-style: italic;
  letter-spacing: 0.05em;
}
  • Vectors and Matrices: Academic conventions dictate that vectors and matrices appear in bold upright or bold italic type rather than standard italics. Publishers often use classes on the variable tag (e.g., <var class="vector">v</var>) paired with CSS: 
    var.vector {
  font-style: normal;
  font-weight: bold;
}
  • Handling Indices: Complex variables often contain subscripts or superscripts. Nesting <sub> and <sup> within <var> (or vice versa) maintains semantic grouping while styling components properly: 
    <var>x<sub><var>i</var></sub></var>

Relationship with MathML

For extensive equations, MathML (<math>) provides a robust XML-based standard using the <mi> (math identifier) tag. However, the standard HTML <var> element remains essential in academic workflows. It offers a lightweight, dependency-free alternative for referencing variables within narrative paragraphs without the overhead of loading full MathML blocks or JavaScript-driven rendering engines like MathJax or KaTeX. When used systematically, <var> bridges standard web typography and rigorous scientific notation.
