Understanding the HTML ol start Attribute

This article explains the purpose, syntax, and behavior of the start attribute on the HTML ordered list (<ol>) element. It covers how this attribute controls the initial sequence value of a list, how it interacts with non-numeric numbering styles such as letters and Roman numerals, and when to use it effectively in web development.

The Purpose of the start Attribute

By default, an HTML ordered list (<ol>) begins numbering its items (<li>) at 1. The start attribute allows developers to override this default behavior and specify an alternative starting integer for the list.

This is particularly useful when dividing a single logical list across multiple sections, such as interrupting a step-by-step tutorial with paragraphs, blockquotes, or code snippets, and resuming the numbering seamlessly in a new list block.

Syntax and Integer-Only Values

The start attribute accepts only an integer value. Even if the list is styled to display letters (A, B, C) or Roman numerals (I, II, III) using the type attribute or CSS list-style-type, the start value must always be specified as an Arabic numeral.

<!-- Starts numbering at 5 -->
<ol start="5">
  <li>Fifth item</li>
  <li>Sixth item</li>
</ol>

<!-- Starts lettering at 'C' (the 3rd letter of the alphabet) -->
<ol type="A" start="3">
  <li>Third item (C)</li>
  <li>Fourth item (D)</li>
</ol>

The browser automatically converts the integer into the appropriate representation based on the defined list type.

Negative Numbers and Zero

The start attribute fully supports negative integers and zero. When a negative number or zero is assigned, the list counts upward sequentially through negative values to positive values:

<ol start="-1">
  <li>Minus one</li>
  <li>Zero</li>
  <li>One</li>
</ol>

Interaction with the reversed Attribute

The start attribute can be combined with the boolean reversed attribute, which causes the list items to count downward instead of upward. When both attributes are present, start dictates the highest number from which the list counts down:

<ol start="10" reversed>
  <li>Ten</li>
  <li>Nine</li>
  <li>Eight</li>
</ol>

If reversed is used without start, modern browsers default the starting value to the total count of items contained in the list.
