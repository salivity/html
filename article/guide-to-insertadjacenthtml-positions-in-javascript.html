Guide to insertAdjacentHTML Positions in JavaScript

The insertAdjacentHTML() method in JavaScript provides a fast and efficient way to insert raw HTML markup into the Document Object Model (DOM) relative to a specific element. Unlike innerHTML, it inserts new nodes without re-parsing existing elements inside the target container, preserving event listeners and state. The method requires two parameters: the insertion position and the HTML string to parse. This guide details the four distinct positional arguments—beforebegin, afterbegin, beforeend, and afterend—to help you accurately place elements within the DOM tree.

Syntax and Visual Model

The method follows this basic syntax:

element.insertAdjacentHTML(position, text);

To visualize how the four positions correspond to an existing HTML element, consider the following diagram:

<!-- 'beforebegin' -->
<div id="target">
  <!-- 'afterbegin' -->
  Existing content goes here.
  <!-- 'beforeend' -->
</div>
<!-- 'afterend' -->

The Four Positional Arguments

1. beforebegin

  • Placement: Inserts the HTML immediately before the target element itself, as a preceding sibling.
  • Scope: Outside the target element.
  • Requirement: The target element must be attached to the DOM tree and have a parent element. If the target element has no parent, this operation throws a DOMException.

2. afterbegin

  • Placement: Inserts the HTML inside the target element, immediately before its first child node.
  • Scope: Inside the target element.
  • Use Case: Ideal for prepending content, such as adding a new item to the top of a list or inserting a notification banner at the beginning of a container.

3. beforeend

  • Placement: Inserts the HTML inside the target element, immediately after its last child node.
  • Scope: Inside the target element.
  • Use Case: Ideal for appending content, such as adding a new row to the end of a table or appending messages to a chat log.

4. afterend

  • Placement: Inserts the HTML immediately after the target element itself, as a following sibling.
  • Scope: Outside the target element.
  • Requirement: Like beforebegin, the target element must have a parent node for this operation to succeed.

Practical Example

Consider the following HTML structure:

<div id="container">
  <p id="target">Target Text</p>
</div>

Executing the four positions sequentially on #target:

const target = document.getElementById('target');

target.insertAdjacentHTML('beforebegin', '<span>Before Begin</span>');
target.insertAdjacentHTML('afterbegin', '<strong>After Begin | </strong>');
target.insertAdjacentHTML('beforeend', '<strong> | Before End</strong>');
target.insertAdjacentHTML('afterend', '<span>After End</span>');

The resulting DOM structure will be:

<div id="container">
  <span>Before Begin</span>
  <p id="target">
    <strong>After Begin | </strong>
    Target Text
    <strong> | Before End</strong>
  </p>
  <span>After End</span>
</div>
