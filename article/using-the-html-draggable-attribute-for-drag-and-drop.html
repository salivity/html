Using the HTML draggable Attribute for Drag and Drop

The HTML draggable attribute is a native global attribute that defines whether an element can be dragged using the browser's built-in Drag and Drop API. By setting this attribute, developers can create interactive user interfaces—such as kanban boards, reorderable lists, and file drop zones—without relying on heavy third-party JavaScript libraries. This article explains how the draggable attribute works, how it interacts with native drag events, and how to configure both source elements and drop zones for seamless drag-and-drop functionality.

Understanding the draggable Attribute

The draggable attribute accepts three possible values:

  • true: Explicitly allows the element to be dragged.
  • false: Prevents the element from being dragged.
  • auto: Uses the browser's default behavior.

By default, standard HTML text selections, images (<img>), and anchor tags (<a>) with an href attribute are draggable by default (draggable="auto"). To make other HTML elements—such as <div>, <article>, or <li>—draggable, you must explicitly set draggable="true".

<div draggable="true" id="drag-source">Drag this item</div>

The Role of the DataTransfer Object

Setting draggable="true" provides visual feedback, allowing the user to initiate a drag operation, but it does not move data by itself. Native drag-and-drop requires JavaScript to manage the payload using the DataTransfer object.

During the drag lifecycle, the DataTransfer object holds the data being dragged and specifies the allowed drag operations (such as copy, move, or link).

Handling Source Events

To manage the element being dragged, listen for drag events on the source element:

  1. dragstart: Fires when the user starts dragging. This is where you configure the data payload using event.dataTransfer.setData(format, data).
  2. dragend: Fires when the drag operation completes (either dropped or canceled). This event is typically used to reset visual styles, such as opacity.
const dragSource = document.getElementById('drag-source');

dragSource.addEventListener('dragstart', (event) => {
  event.dataTransfer.setData('text/plain', event.target.id);
  event.dataTransfer.effectAllowed = 'move';
});

Configuring the Drop Target

By default, web browsers prevent dropping elements onto other elements. To turn a standard element into a valid drop target, you must intercept specific target events:

  1. dragover: Fires continuously as an item is dragged over a valid target. You must call event.preventDefault() inside this handler to permit the drop.
  2. drop: Fires when the item is released over the target. Call event.preventDefault() to stop the browser's default action (such as opening a dragged link or file) and retrieve the data via event.dataTransfer.getData().
const dropZone = document.getElementById('drop-zone');

dropZone.addEventListener('dragover', (event) => {
  event.preventDefault(); // Necessary to allow dropping
  event.dataTransfer.dropEffect = 'move';
});

dropZone.addEventListener('drop', (event) => {
  event.preventDefault();
  const id = event.dataTransfer.getData('text/plain');
  const draggedElement = document.getElementById(id);
  dropZone.appendChild(draggedElement);
});

Summary

The draggable attribute serves as the foundational toggle that tells the browser an element can initiate native drag interactions. Once enabled, the browser handles the rendering and movement lifecycle, while the DataTransfer object and standard DOM events (dragstart, dragover, and drop) allow you to manage state and relocate elements reliably across the DOM.
