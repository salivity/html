How to Use apple-mobile-web-app-status-bar-style

The apple-mobile-web-app-status-bar-style meta tag controls the appearance of the top status bar on iOS devices when a website is launched as a Progressive Web App (PWA) from the home screen. This article details how the tag works, its required prerequisites, the available styling values, and how to handle content positioning to ensure an optimal visual presentation on Apple mobile devices.

Prerequisites for the Meta Tag

The apple-mobile-web-app-status-bar-style tag does not affect standard Safari browsing. It only takes effect after a user adds the webpage to their iOS Home Screen and opens it as a standalone web application.

For the status bar tag to function, you must also include the apple-mobile-web-app-capable meta tag set to yes:

<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="default">

Supported Values and Their Effects

The content attribute accepts one of three values:

1. default

<meta name="apple-mobile-web-app-status-bar-style" content="default">
  • Appearance: A standard status bar with a white background and dark text and icons.
  • Layout behavior: The status bar occupies its own space at the top of the screen. Web content begins immediately below the status bar, preventing any overlapping.

2. black

<meta name="apple-mobile-web-app-status-bar-style" content="black">
  • Appearance: An opaque black background with white text and icons.
  • Layout behavior: Like the default setting, the status bar pushes the web content down. Content begins below the status bar rather than underneath it.

3. black-translucent

<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
  • Appearance: A transparent status bar with white text and icons.
  • Layout behavior: The status bar floats directly on top of the web content. The webpage extends to fill the entire screen, including the area behind the status bar, time, and battery indicators.

Handling Layout with black-translucent

When using black-translucent, page elements at the top of your layout (such as headers, navigation bars, or titles) will render underneath the status bar indicators unless compensated for with CSS.

To prevent content from colliding with system indicators:

  1. Enable full-bleed layout in your viewport tag:
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
  1. Use CSS safe area environment variables to add padding to the top of your layout:
header {
  padding-top: env(safe-area-inset-top);
}

This ensures that your background color or image fills the entire display while keeping interactive elements and text safely below the iOS status bar.
