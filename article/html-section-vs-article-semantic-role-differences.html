HTML Section vs Article: Semantic Role Differences

HTML5 introduced semantic tags to give structure and meaning to web content, with <article> and <section> being two of the most frequently confused elements. The primary difference lies in independence: an <article> is designed to hold self-contained, independently distributable content that makes sense on its own, whereas a <section> represents a thematic grouping of related content that forms part of a larger document. Understanding this distinction is vital for proper document outlining, search engine optimization (SEO), and screen reader accessibility.

The Semantic Role of <article>

The <article> element represents a complete, self-contained composition in a document, page, application, or site. The defining characteristic of an <article> is that it could theoretically be extracted and distributed independently via RSS, syndicated across other platforms, or read in isolation without losing its core meaning.

Common use cases for <article> include:

  • A blog post or news story
  • A forum post or user review
  • An individual comment on a post
  • An interactive widget or independent product card

If the content can be shared outside the context of the current page and still make complete sense to the reader, wrap it in an <article>.

The Semantic Role of <section>

The <section> element represents a generic standalone section of a document that groups related content by a specific theme. Unlike an <article>, a <section> is not intended to be independently distributed; it relies on the broader context of the page or document to provide its full meaning.

Per the HTML specification, a <section> should almost always contain an appropriate heading (<h2> through <h6>) to define its theme.

Common use cases for <section> include:

  • Chapters in a long-form document
  • Distinct page areas such as "About Us," "Services," or "Contact"
  • Tabbed panels in a user interface
  • A specific section of a terms of service agreement

If the content represents a distinct thematic chapter within a broader page, wrap it in a <section>. If the element is needed purely for styling, layout, or scripting without any thematic meaning, use a generic <div> instead.

How to Nest <section> and <article>

HTML allows <section> and <article> elements to be nested inside one another depending on the document's structure:

  • <article> inside <section>: A thematic area of a webpage can contain multiple independent entries. For example, a "Latest News" <section> might contain multiple <article> elements, each representing an individual news report.
  • <section> inside <article>: A single, long piece of self-contained content can be divided into thematic subsections. For example, a detailed blog post wrapped in an <article> can use multiple <section> tags to separate the introduction, core methodology, and conclusion.

The Syndication Test

To quickly decide between the two elements, apply the syndication test:

  1. Could this piece of content be syndicated in an RSS feed or shared as a standalone card elsewhere? If yes, use <article>.
  2. Is this content a thematic sub-part of a larger whole that requires a heading? If yes, use <section>.
  3. Is the wrapper only needed for CSS styling or JavaScript hooks? If yes, use <div>.
