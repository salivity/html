Understanding Apple Touch Icon in iOS Safari

The <link rel="apple-touch-icon"> element is an HTML tag used to specify the graphic icon that represents a website or web application on Apple devices. When a user browsing in iOS Safari selects the "Add to Home Screen" option, the operating system uses the image defined by this tag as the launcher icon on their home screen. Without it, Safari automatically generates a low-fidelity, scaled-down screenshot of the webpage instead, resulting in an unpolished appearance.

Primary Purpose and Functionality

When building Progressive Web Apps (PWAs) or mobile-friendly websites, providing a native app-like experience is essential. The primary purpose of the apple-touch-icon tag is to bridge the visual gap between standard web links and native iOS applications. By declaring this tag in the <head> of an HTML document, developers ensure that their branding remains crisp, professional, and easily recognizable on an iPhone or iPad home screen.

Basic Implementation

To declare a home screen icon, place the tag in the <head> section of your HTML document:

<link rel="apple-touch-icon" href="/images/apple-touch-icon.png">

If no specific size attribute is declared, iOS looks for this default tag. Additionally, iOS Safari automatically scans the website's root directory for a file named apple-touch-icon.png, but explicitly defining it in the HTML ensures reliability across subdirectories and edge cases.

Sizing and Device Compatibility

While iOS can scale a single high-resolution image down to fit various screen densities, providing distinct dimensions ensures maximum visual clarity across different Apple devices:

  • 180x180 pixels: The standard and most important size, used for high-resolution iPhone displays.
  • 167x167 pixels: Optimized specifically for iPad Pro displays.
  • 152x152 pixels: Optimized for standard iPad and iPad mini Retina displays.
  • 120x120 pixels: Used for legacy or smaller Retina iPhone displays.

You can declare multiple sizes using the sizes attribute:

<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon-180x180.png">
<link rel="apple-touch-icon" sizes="152x152" href="/apple-touch-icon-152x152.png">
<link rel="apple-touch-icon" sizes="167x167" href="/apple-touch-icon-167x167.png">

If you prefer to maintain only one asset, a single 180x180 PNG file declared without a sizes attribute will be scaled down automatically by modern iOS versions with negligible quality loss.

Design and Formatting Requirements

iOS treats home screen web icons with the same design parameters as native app icons:

  • Format: The icon must be saved in PNG format.
  • Corners: Supply a flat, square image. Do not pre-round the corners; iOS automatically applies the standard rounded rectangle mask (squircle) to the icon.
  • Transparency: Avoid transparent backgrounds. iOS does not support transparency in home screen icons and will typically fill transparent pixels with solid black.
