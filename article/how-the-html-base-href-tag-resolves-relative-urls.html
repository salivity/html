How the HTML Base Href Tag Resolves Relative URLs

The <base href="..."> tag establishes a single, document-wide reference point that browsers use to resolve all relative paths on an HTML page. By declaring this tag inside the document's <head>, web developers can centrally control where relative links—such as stylesheets, images, scripts, and hyperlinks—fetch their resources, regardless of the page's current directory or URL rewrite rules.

How the Base URL Resolution Works

Under default browser behavior, relative paths resolve against the current document's actual URL. For example, if a page resides at https://example.com/blog/posts/ and loads an image with src="photo.jpg", the browser requests https://example.com/blog/posts/photo.jpg.

When you include a <base href="..."> tag, the browser overrides the current page location and uses the declared base URL as the prefix for all relative assets.

<head>
  <base href="https://example.com/assets/">
  <link rel="stylesheet" href="css/style.css">
  <script src="js/main.js"></script>
</head>

In this scenario:

  • css/style.css resolves to https://example.com/assets/css/style.css.
  • js/main.js resolves to https://example.com/assets/js/main.js.

Affected HTML Elements

The <base> tag affects any attribute accepting a relative URI. Common elements include:

  • Hyperlinks: <a href="...">
  • Media and embedded elements: <img src="...">, <audio src="...">, <video src="...">, and <iframe src="...">
  • External resources: <link href="..."> and <script src="...">
  • Form handling: <form action="...">

Directory Slashes and Resolution Rules

The presence or absence of a trailing slash in the href attribute changes how relative paths are evaluated:

  • With a trailing slash (https://example.com/subfolder/): A path like script.js becomes https://example.com/subfolder/script.js.
  • Without a trailing slash (https://example.com/subfolder): The browser treats the last segment as a file. A path like script.js replaces the last segment, resulting in https://example.com/script.js.

Root-relative paths (paths starting with /) ignore any subdirectories defined in the <base> tag and resolve directly against the origin host. If the base is https://example.com/app/, a link to /style.css resolves to https://example.com/style.css, not https://example.com/app/style.css.

Important Considerations and Pitfalls

  1. Placement: The <base> element must be placed inside the <head> tag before any elements that load external resources. Any assets declared prior to the <base> tag resolve against the standard document location.
  2. Single Occurrence: An HTML document can contain only one <base> tag. If multiple instances are declared, the browser honors only the first one.
  3. Anchor Link Interference: The <base> tag applies to fragment identifiers. A standard anchor link such as <a href="#section"> will resolve to [base-url]#section rather than jumping to an element on the current page. If the base URL differs from the current page URL, clicking an anchor link may navigate away from the current view.
