What Is the Web App Manifest in HTML?

The Web App Manifest is a core technology behind Progressive Web Apps (PWAs) that allows developers to control how their web application appears and behaves when installed on a user's device. Linked directly in the HTML <head> using <link rel="manifest" href="/manifest.json">, this JSON-formatted configuration file provides the browser with essential metadata needed to transform a standard website into an installable, native-like application.

The Mechanism of <link rel="manifest">

The <link rel="manifest"> tag acts as a bridge between the HTML document and the manifest file. When a browser loads the webpage, it parses this tag and fetches the JSON file. The browser then evaluates the metadata to determine whether the site meets the installation criteria for modern platforms, such as Android, iOS, Windows, and macOS. Without this tag, browsers treat the site purely as a traditional webpage, disabling native installation prompts.

Key Capabilities and Properties

The Web App Manifest defines several critical properties that dictate the user experience:

  • Identity and Naming: Properties such as name and short_name define the title displayed on the splash screen, app stores, and beneath the app icon on a user's home screen or desktop.
  • Visual Assets: The icons array allows developers to supply application icons in multiple resolutions, formats, and maskable variants. The operating system utilizes these icons across app switchers, system settings, and launch surfaces.
  • Display Mode: The display member determines how much browser interface is visible to the user. Options like standalone or fullscreen remove the browser URL bar and navigation buttons, giving the application the look and feel of a native program.
  • Start Configuration: The start_url property defines the exact page the app should load when opened from the device, while orientation can lock the application in landscape or portrait mode.
  • Branding and Theming: The theme_color customizes the operating system's status bar and application frame, while background_color sets the initial canvas color for smooth transitions before stylesheets load.

Enabling Native Installation

The primary role of the Web App Manifest is facilitating the "Add to Home Screen" or "Install App" capability. When combined with HTTPS and an active service worker, the presence of a valid manifest signals to modern browsers that the application is ready for offline-capable, standalone usage. This enables browsers to present automated install banners to users, establishing persistent access on mobile and desktop operating systems.
