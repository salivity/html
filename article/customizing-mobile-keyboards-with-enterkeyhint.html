Customizing Mobile Keyboards with enterkeyhint

The enterkeyhint attribute is a global HTML attribute that customizes the label or icon displayed on the Enter or action key of mobile virtual keyboards. By aligning the Enter key's appearance with the expected user action, developers can significantly improve mobile form usability and reduce user confusion. This article explains how enterkeyhint works, details its supported values, and highlights best practices for implementing it in web applications.

How the enterkeyhint Attribute Works

When a user focuses on a text input (<input> or <textarea>) on a mobile device, a virtual keyboard appears. By default, the action key—typically the Enter key in the lower-right corner—displays a generic icon, a return arrow, or text based on the input type.

Applying the enterkeyhint attribute instructs the browser to request a specific label or icon from the operating system's on-screen keyboard. This gives users immediate visual context regarding what happens when they tap that key.

<!-- Example of an input configured for search -->
<input type="text" enterkeyhint="search" placeholder="Search articles...">

Supported Values

The enterkeyhint attribute accepts seven standardized values, each designed for a specific user interaction:

  • enter: Typically displays a return arrow or the word "Return" / "Enter". It indicates that pressing the key will insert a newline character or perform standard entry behavior.
  • done: Displays "Done" or a checkmark icon. It indicates that the user has completed typing and that the keyboard should typically close.
  • go: Displays "Go" or a forward arrow. It signals that the action will navigate the user to the destination of the entered text (such as entering a URL or initiating a primary action).
  • next: Displays "Next" or an arrow pointing forward. It indicates that tapping the key will move focus to the next input field in a sequence.
  • previous: Displays "Previous" or a backward arrow. It indicates moving focus to the previous input field (rarely used, but supported).
  • search: Displays a magnifying glass icon or "Search". It indicates that the input will execute a search query.
  • send: Displays a paper airplane icon or "Send". It indicates that the message or form data will be dispatched immediately.

Practical Implementation

Here is an example demonstrating different enterkeyhint configurations across a multi-step form:

<form action="/submit" method="post">
  <!-- Signals moving to the next field -->
  <label for="first-name">First Name</label>
  <input type="text" id="first-name" enterkeyhint="next">

  <!-- Signals navigation or lookup -->
  <label for="zip">Zip Code</label>
  <input type="text" id="zip" enterkeyhint="go">

  <!-- Signals final submission in a chat or comment box -->
  <label for="comment">Comment</label>
  <textarea id="comment" enterkeyhint="send"></textarea>
</form>

Important Considerations

  • Visual Only: The enterkeyhint attribute only alters the visual representation of the key. It does not automatically bind actions such as form submission or focus shifting. Developers must still handle form submission logic or JavaScript keydown events manually.
  • Virtual Keyboards Only: This attribute affects only on-screen virtual keyboards on devices like smartphones and tablets. It has no effect on physical hardware keyboards.
  • Platform Fallbacks: The operating system determines how the hint is rendered. If an operating system does not support a specific keyword icon, it will fall back to a generic default key without breaking functionality.
