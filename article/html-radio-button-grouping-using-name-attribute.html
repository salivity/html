HTML Radio Button Grouping Using Name Attribute

In HTML forms, radio buttons are designed to let users select exactly one option from a predefined set of choices. This article explains how the name attribute links individual radio inputs into a unified selection group, ensuring mutual exclusivity across options. You will learn the mechanics behind this behavior, the role of supporting attributes like value and id, and how to manage multiple distinct groups within the same form.

How the name Attribute Groups Radio Buttons

The name attribute acts as a shared identifier for <input type="radio"> elements. When multiple radio buttons share the exact same name value, the web browser automatically treats them as members of a single, mutually exclusive group.

When a user selects any radio button within a group, the browser automatically deselects whichever radio button was previously selected in that same group.

<form>
  <p>Select your preferred contact method:</p>
  
  <input type="radio" id="email" name="contact_method" value="email">
  <label for="email">Email</label>

  <input type="radio" id="phone" name="contact_method" value="phone">
  <label for="phone">Phone</label>

  <input type="radio" id="mail" name="contact_method" value="mail">
  <label for="mail">Postal Mail</label>
</form>

In this example, all three inputs share name="contact_method". Clicking "Phone" will immediately uncheck "Email" if it was already selected.

Essential Related Attributes

To make a radio button group function properly for both users and form processing, several other attributes work alongside name:

  • value: Defines the data sent to the server when the form is submitted. While all radio buttons in a group share the same name, each button should have a unique value representing that specific choice (e.g., value="email").
  • id: Must be unique to each element on the page. It binds the input to its corresponding <label> element using the for attribute.
  • checked: A boolean attribute used to set the default selected option when the page loads. Only one radio button in a shared group should have the checked attribute.

Handling Multiple Groups on a Single Form

A single web form can contain multiple, independent radio button groups. The browser isolates each group based entirely on the value of the name attribute.

<form>
  <!-- Group 1: Shipping Speed -->
  <fieldset>
    <legend>Shipping Method</legend>
    <input type="radio" id="standard" name="shipping" value="standard" checked>
    <label for="standard">Standard</label>

    <input type="radio" id="express" name="shipping" value="express">
    <label for="express">Express</label>
  </fieldset>

  <!-- Group 2: Payment Method -->
  <fieldset>
    <legend>Payment Method</legend>
    <input type="radio" id="credit" name="payment" value="credit">
    <label for="credit">Credit Card</label>

    <input type="radio" id="paypal" name="payment" value="paypal">
    <label for="paypal">PayPal</label>
  </fieldset>
</form>

Because the first set uses name="shipping" and the second set uses name="payment", selecting an option in the payment group will not affect the selection in the shipping group.

Form Submission Behavior

When a user submits a form, only the selected radio button from each group is transmitted as a key-value pair. If the user selects "Express" shipping and "PayPal" payment in the example above, the submitted payload includes:

shipping=express
payment=paypal

Unselected radio buttons are ignored entirely during form submission, preventing empty or duplicate parameters for that group.
