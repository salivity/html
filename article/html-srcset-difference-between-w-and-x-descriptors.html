HTML srcset: Difference Between w and x Descriptors

The HTML srcset attribute provides a responsive way to serve different image files based on device characteristics, using either the w (width) or x (pixel density) descriptor. While the x descriptor serves images based purely on the screen's device pixel ratio for fixed-size layouts, the w descriptor specifies the image file's actual pixel width, allowing the browser to dynamically choose the optimal image based on both the screen resolution and the layout width defined in the sizes attribute.

The x Descriptor: Pixel Density

The x descriptor targets device pixel density (DPR), such as standard displays (1x), Retina displays (2x), or ultra-high-density mobile screens (3x).

<img src="logo-1x.png" 
     srcset="logo-1x.png 1x, logo-2x.png 2x, logo-3x.png 3x" 
     alt="Company Logo">

When using x, the browser queries only the screen's hardware resolution. If a device has a 2x display, it downloads the logo-2x.png file, regardless of the browser window's size. This makes the x descriptor ideal for fixed-dimension elements that never change their CSS layout size across viewports, such as profile avatars, icons, and fixed-width logos.

The w Descriptor: Intrinsic Image Width

The w descriptor tells the browser the true pixel width of the source image file before it downloads it. For example, an image file that is 800 pixels wide is marked as 800w.

<img src="hero-fallback.jpg"
     srcset="hero-small.jpg 400w, hero-medium.jpg 800w, hero-large.jpg 1600w"
     sizes="(max-width: 600px) 100vw, 50vw"
     alt="Scenic Landscape">

Unlike the x descriptor, the w descriptor requires the sizes attribute to function effectively. The sizes attribute informs the browser how wide the image will render on the screen at different media queries.

With this information, the browser performs a calculation:

\[\text{Required Pixels} = \text{Display Slot Width} \times \text{Device Pixel Ratio}\]

The browser then selects the smallest file from the srcset list that meets or exceeds this calculated pixel requirement.

Key Differences

  • Layout Flexibility: The x descriptor assumes the layout size remains constant; it cannot adapt to responsive, fluid layouts. The w descriptor accounts for varying display sizes and responsive CSS layouts.
  • Dependency on the sizes Attribute: The x descriptor functions without the sizes attribute. The w descriptor requires sizes (or defaults to 100vw), as the browser must know the display width to choose the correct width descriptor.
  • Browser Decision Control: The x descriptor is restrictive, forcing image selection based solely on display hardware. The w descriptor gives the browser full intelligence to balance layout size, screen density, and even user network preferences (such as data-saver modes) to select the most efficient resource.
