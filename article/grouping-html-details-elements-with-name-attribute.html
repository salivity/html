Grouping HTML Details Elements with Name Attribute

This article explains the purpose and functionality of the name attribute when applied to HTML <details> elements. You will learn how this attribute enables native exclusive accordions, how it replaces the need for custom JavaScript, and how to implement it correctly in modern web development.

The Purpose of the name Attribute

The primary purpose of adding a name attribute to the HTML <details> element is to create an "exclusive accordion." In an exclusive accordion, only one section can be expanded at a time. When a user opens a <details> element, any other open <details> element that shares the exact same name attribute will automatically close.

Historically, achieving this behavior required custom JavaScript to listen for toggle events, track active states, and manually remove the open attribute from sibling elements. The name attribute standardizes this behavior natively within the browser, mirroring how the name attribute functions on <input type="radio"> elements.

How to Implement Exclusive Accordions

To link multiple disclosure widgets together, assign identical string values to the name attribute across each <details> tag.

<details name="faq-group">
  <summary>What is HTML?</summary>
  <p>HTML stands for HyperText Markup Language.</p>
</details>

<details name="faq-group">
  <summary>What is CSS?</summary>
  <p>CSS is used for styling web documents.</p>
</details>

<details name="faq-group">
  <summary>What is JavaScript?</summary>
  <p>JavaScript provides interactive behavior on web pages.</p>
</details>

In this example, opening the "What is CSS?" section automatically collapses the "What is HTML?" section if it was already open.

Key Benefits

  • No JavaScript Required: Reduces the amount of client-side code, lowering file sizes and preventing execution overhead.
  • Built-in Accessibility: The native <details> and <summary> elements handle focus states, keyboard interactions (Space and Enter keys), and ARIA attributes out of the box, ensuring compatibility with assistive technologies.
  • Declarative and Maintainable: Grouping logic is managed purely through HTML semantics, making the codebase easier to read and maintain.
