How the HTML5 Fullscreen API Works

The HTML5 Fullscreen API provides a programmatic way for web developers to expand a specific DOM element, such as a video, canvas, or container, to occupy the user's entire display monitor. This guide explains the core methods behind invoking full-screen mode, the security constraints that dictate its execution, how CSS styles the expanded element, and how to exit the full-screen state properly.

Requesting Fullscreen Mode

To request that an element expand across the entire monitor, the API provides the Element.requestFullscreen() method. When invoked on a targeted DOM element, the browser requests the operating system to allocate the full viewport display to that single element, hiding standard browser user interface elements such as toolbars, tabs, and the address bar.

Because requestFullscreen() is asynchronous, it returns a Promise. The promise resolves when the full-screen switch succeeds, or rejects if the request fails (for instance, if permissions are denied).

const element = document.getElementById("my-video");

function toggleFullscreen() {
  element.requestFullscreen()
    .then(() => {
      console.log("Element is now fullscreen");
    })
    .catch((err) => {
      console.error(`Error attempting to enable fullscreen: ${err.message}`);
    });
}

Security and User Activation

Browsers strictly govern the Fullscreen API to prevent malicious websites from hijacking a user's screen or spoofing operating system interfaces.

  1. Transient User Activation: The requestFullscreen() method can only be executed in response to a direct user interaction, such as a click, pointerup, or keydown event. Calling this method on page load or within an unprompted script will be rejected automatically.
  2. Iframe Permissions: If an element inside an <iframe> needs to enter full-screen mode, the parent frame must explicitly grant permission using the allow="fullscreen" attribute.

Tracking Fullscreen State

The Document interface tracks whether an element currently occupies the display and whether full-screen mode is supported:

  • document.fullscreenElement: Returns the element currently presented in full-screen mode, or null if the page is in standard view.
  • document.fullscreenEnabled: A boolean indicating whether the host environment supports and allows full-screen requests.
  • fullscreenchange event: Dispatched to the document whenever an element enters or exits full-screen mode.
  • fullscreenerror event: Dispatched if a full-screen transition cannot be completed.

Exiting Fullscreen Mode

Exiting full-screen view is managed at the Document level rather than on the individual element. Calling document.exitFullscreen() returns the browser viewport to its standard display state. Users can also exit at any time using standard hardware keys, such as the Escape key.

function exitFullscreen() {
  if (document.fullscreenElement) {
    document.exitFullscreen();
  }
}

Styling the Fullscreen Element

When an element enters full-screen mode, browsers automatically apply default styles to center it and set its dimensions to fill the monitor. Web developers can customize these styles using the :fullscreen CSS pseudo-class and style the area behind the element using the ::backdrop pseudo-element.

/* Style applied only when the element is fullscreen */
#my-video:fullscreen {
  width: 100vw;
  height: 100vh;
  background-color: #000;
}

/* Style the layer behind the fullscreen element */
#my-video::backdrop {
  background-color: rgba(0, 0, 0, 0.8);
}
