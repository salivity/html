Manipulating HTML Classes with classList API

The JavaScript classList API provides a clean, native way to manipulate an element's CSS classes without parsing or overwriting the entire class attribute string. By exposing methods like add(), remove(), toggle(), and contains(), this read-only DOMTokenList collection allows developers to dynamically alter styles and element states safely and efficiently.

Understanding classList

Before classList, modifying an element's classes required manipulating element.className as a raw string, which often led to accidental overwrites or cumbersome regular expressions. The classList property returns a live collection of the class attributes assigned to an element, providing dedicated methods to interact with individual classes.

const element = document.querySelector('.card');

classList.add()

The add() method appends one or more specified class names to the element. If the specified class already exists on the element, it is ignored, preventing duplicate class names.

// Add a single class
element.classList.add('active');

// Add multiple classes
element.classList.add('highlighted', 'visible');

classList.remove()

The remove() method deletes one or more specified class names from the element. If a class passed to remove() does not exist on the element, the method simply skips it without throwing an error.

// Remove a single class
element.classList.remove('active');

// Remove multiple classes
element.classList.remove('highlighted', 'visible');

classList.toggle()

The toggle() method handles switching a class on and off. If the class exists on the element, toggle() removes it; if the class does not exist, toggle() adds it. It returns a boolean value (true if the class was added, false if it was removed).

// Toggles the 'hidden' class
const isHidden = element.classList.toggle('hidden');

toggle() also accepts an optional second argument—a boolean force condition. If the condition evaluates to true, the class is added; if false, the class is removed.

// Adds 'collapsed' if isOpen is false, removes it if isOpen is true
element.classList.toggle('collapsed', !isOpen);

classList.contains()

The contains() method checks whether a specific class exists on an element. It accepts a single class name string and returns true if the class is present, or false if it is not.

if (element.classList.contains('active')) {
  console.log('The element is currently active.');
}

This method is commonly used in conditional logic before triggering animations, state changes, or accessibility updates.
