HTML img sizes Media Queries Explained

The sizes attribute in an HTML <img> tag works in tandem with srcset to tell the browser the exact display width of an image across various screen sizes. By evaluating media query conditions defined in sizes, the browser can determine the layout size of an image before downloading it and before any external CSS stylesheets are fully parsed. This allows the browser's preload scanner to immediately select and request the most appropriate image source from srcset, optimizing network performance and avoiding layout shifts.

Why Media Queries Are Needed in the sizes Attribute

Modern browsers use a preload scanner to fetch external resources like images as early as possible to speed up page loading. However, this scanning happens before the Document Object Model (DOM) and CSS Object Model (CSSOM) are fully constructed.

Because the browser does not yet know the CSS layout, it cannot determine how wide an image element will be rendered on the screen. If an image is presented solely with a srcset containing multiple pixel widths (such as 400w, 800w, 1200w), the browser assumes the image will occupy 100vw (100% of the viewport width). This assumption often leads to downloading unnecessarily large assets on multi-column or desktop layouts.

The media query conditions in sizes bridge this gap by explicitly providing the layout rules directly inside the HTML markup.

Syntax and Evaluation

The sizes attribute consists of a comma-separated list of media condition and length pairs, followed by a fallback length:

<img 
  src="photo-medium.jpg"
  srcset="photo-small.jpg 400w, photo-medium.jpg 800w, photo-large.jpg 1200w"
  sizes="(max-width: 600px) 100vw, (max-width: 1024px) 50vw, 800px" 
  alt="Example image" />

The browser evaluates these media conditions sequentially from left to right:

  1. First Condition: If the viewport width is 600px or less, the image slot is calculated as 100vw (the full width of the screen).
  2. Second Condition: If the first condition fails and the viewport width is 1024px or less, the slot size evaluates to 50vw (half the viewport width, typical for a two-column layout).
  3. Fallback Value: If no media conditions match, the browser falls back to the final length, treating the slot as 800px wide.

Once the browser determines the matching slot width, it multiplies that value by the user's Device Pixel Ratio (DPR) and selects the best matching candidate from the srcset list.

Key Rules for Using sizes

  • Units: Slot widths can be specified using absolute or relative units such as px, em, rem, vw, or calc(). Percentages (%) are not valid because the browser does not know the parent container's dimensions at parse time.
  • Order Matters: Because the browser selects the first condition that evaluates to true, media queries must be ordered appropriately (for example, smallest to largest when using min-width, or largest to smallest when using max-width).
  • Fallback Required: The last entry in the sizes attribute must always be an unconditional length that serves as the default value when no preceding media queries match.
