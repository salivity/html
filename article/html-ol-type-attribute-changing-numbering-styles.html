HTML OL Type Attribute: Changing Numbering Styles

The type attribute on an HTML ordered list (<ol>) element is used to set the numbering style of list items directly in HTML markup. This article explains the primary function of the type attribute, outlines the five supported values—including standard numbers, letters, and Roman numerals—and clarifies when to use this attribute versus modern CSS styling.

Purpose of the type Attribute

By default, an HTML ordered list renders using standard decimal numbers (1, 2, 3, etc.). The type attribute allows developers and content authors to explicitly define the numbering scheme used for the sequence. While visual formatting is typically handled by CSS, the type attribute remains part of the living HTML standard because the marker style often carries structural or semantic meaning—such as in legal outlines, technical specifications, or multiple-choice questions.

Supported type Values

The <ol> element accepts five specific case-sensitive character values:

  • type="1" (Decimal Numbers): The default format. Items are numbered as 1, 2, 3, 4, etc.
  • type="a" (Lowercase Letters): Items are labeled with lowercase letters: a, b, c, d, etc.
  • type="A" (Uppercase Letters): Items are labeled with uppercase letters: A, B, C, D, etc.
  • type="i" (Lowercase Roman Numerals): Items are labeled using lowercase Roman numerals: i, ii, iii, iv, etc.
  • type="I" (Uppercase Roman Numerals): Items are labeled using uppercase Roman numerals: I, II, III, IV, etc.

Syntax Example

To change the list style, apply the attribute to the opening <ol> tag:

<ol type="A">
  <li>First item labeled with capital letters</li>
  <li>Second item labeled with capital letters</li>
  <li>Third item labeled with capital letters</li>
</ol>

In this example, the browser automatically renders the items prefixed with "A.", "B.", and "C." respectively.

HTML type vs. CSS list-style-type

While the CSS property list-style-type offers broader styling options and is preferred for purely aesthetic alterations, the HTML type attribute is appropriate when the list type is intrinsic to the document's content. If changing the numbering scheme would alter the meaning or references within the text (for example, referring to "Option A" or "Section ii"), using the HTML type attribute ensures the content maintains its intended structure even if CSS fails to load or the page is parsed by basic text readers.
