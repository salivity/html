How the HTML ol Reversed Attribute Works

This article provides an overview of the HTML reversed attribute, explaining how it alters the visual numbering sequence of ordered lists (<ol>). You will learn about its syntax, how browsers calculate descending numbers, the distinction between marker numbering and DOM ordering, and how reversed interacts with companion attributes like start and value.

What the reversed Attribute Does

The reversed attribute is a boolean attribute applied to the <ol> (ordered list) element. When present, it instructs the browser to number list items in descending order rather than the default ascending order (1, 2, 3...).

<ol reversed>
  <li>First item</li>
  <li>Second item</li>
  <li>Third item</li>
</ol>

In the example above, the list displays as:

    1. First item
    1. Second item
    1. Third item

DOM Order vs. Visual Numbering

The reversed attribute changes only the numeric markers attached to list items; it does not change the structural order of the elements in the DOM.

  • The first <li> element written in the HTML document remains visually at the top of the list.
  • The last <li> element remains visually at the bottom.
  • Screen readers and document parsers still navigate the content in the original source order from top to bottom, but accessibility APIs expose the decrementing numerical values.

Default Starting Values

When the reversed attribute is used without a specified start attribute, the browser automatically counts the total number of child <li> elements and uses that count as the starting number.

  • A list with 5 items counts down: 5, 4, 3, 2, 1.
  • A list with 10 items counts down: 10, 9, 8, and so forth.

Interaction with the start Attribute

You can combine reversed with the start attribute to define an explicit starting number. The browser will then decrement sequentially from that specified value.

<ol reversed start="10">
  <li>Top 10 entry</li>
  <li>Top 9 entry</li>
  <li>Top 8 entry</li>
</ol>

Rendering:

    1. Top 10 entry
    1. Top 9 entry
    1. Top 8 entry

Negative numbers and zero are also valid starting points. If an ordered list begins at 1 and contains three items while reversed, the numbers will decrement through zero and into negative integers (1, 0, -1).

Interaction with the value Attribute

Individual <li> elements can have a value attribute that overrides the sequence. When reversed is active:

  • An explicit value sets the number for that specific item.
  • Any subsequent items without an explicit value will continue counting down from that new value.
<ol reversed>
  <li>Item (numbered 3)</li>
  <li value="10">Item (numbered 10)</li>
  <li>Item (numbered 9)</li>
</ol>

Browser Support

The reversed attribute is part of the modern HTML Living Standard and is natively supported across all modern web browsers, including Chrome, Firefox, Safari, and Edge. In unsupported legacy environments, browsers simply ignore the boolean attribute and render the list with standard ascending numbers.
