HTML focus() on Focusable vs Non-Focusable Elements

The HTMLElement.focus() method in JavaScript sets keyboard focus on a specified element, but its behavior varies significantly depending on whether the target element is natively focusable or non-focusable. While interactive elements like buttons and inputs receive focus immediately upon invocation, non-interactive elements like generic text containers completely ignore the call unless explicitly configured with a tabindex attribute.

Native Focusable Elements

Browsers classify certain interactive elements as natively focusable. These include:

  • <input>, <textarea>, and <select>
  • <button>
  • Hyperlinks (<a> and <area>) that contain an href attribute
  • <details> summary elements

When calling .focus() on a native focusable element:

  1. Active Element Updates: The browser updates document.activeElement to point to the targeted element.
  2. Events Fire: The focus and focusin events trigger sequentially. If another element previously had focus, it fires blur and focusout events first.
  3. Visual Indicator: The browser renders its default focus ring or applies custom :focus / :focus-visible CSS rules.
  4. Viewport Adjustment: By default, the browser scrolls the page to bring the focused element into view, unless suppressed using .focus({ preventScroll: true }).

If a native element is disabled via the disabled attribute or marked with the inert attribute, the .focus() method fails silently, leaving focus on the current element.

Non-Focusable Elements

Elements primarily used for layout or content presentation—such as <div>, <span>, <p>, <h1>–<h6>, and section—are not focusable by default.

When calling .focus() on a non-focusable element:

  • No State Change: document.activeElement remains unchanged.
  • No Events: Neither focus nor focusin events are dispatched.
  • No Visual or Viewport Changes: No focus ring appears, and the viewport does not scroll.
  • Silent Failure: The operation fails silently without throwing an error.

Enabling focus() on Non-Focusable Elements

To allow a non-focusable element to respond to the .focus() method, you must add the tabindex HTML attribute.

  • tabindex="-1" (Programmatic Focus): This allows the element to be focused via JavaScript using .focus() without adding it to the sequential keyboard navigation order (the user cannot reach it using the Tab key). This approach is standard for accessible routing, modal dialog focus management, and skip links.
  • tabindex="0" (Interactive Focus): This makes the element focusable via JavaScript and inserts it into the natural keyboard tab order.

Once a valid tabindex is present, the non-focusable element exhibits the same runtime behavior as a native focusable element when .focus() is called.
