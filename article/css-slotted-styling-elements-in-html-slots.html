CSS ::slotted(): Styling Elements in HTML Slots

The CSS ::slotted() pseudo-element enables developers to style elements distributed into a Web Component's <slot> from within the component's Shadow DOM. Under the Web Components standard, the Shadow DOM creates an encapsulation boundary that isolates styles. The ::slotted() pseudo-element acts as a bridge across this boundary, granting parent components controlled styling authority over user-provided nodes without breaking encapsulation.

The Purpose of ::slotted()

When using Web Components, developers often create templates containing <slot> elements as placeholders for external content provided by the consumer of the component (often called "light DOM" content). By default, styles defined inside a Shadow Root do not affect light DOM elements, even when those elements are visually projected into a <slot>.

The ::slotted() pseudo-element solves this problem. It allows a component's internal stylesheet to target and style the elements placed inside its slots, ensuring that injected content harmonizes with the component's design system.

Basic Syntax and Usage

The pseudo-element is applied to the <slot> element, taking a selector as an argument:

/* Styles any <p> element slotted into the component */
::slotted(p) {
  color: #333333;
  font-size: 1rem;
  line-height: 1.5;
}

/* Styles an element with a specific class slotted into a named slot */
slot[name="icon"]::slotted(.custom-icon) {
  width: 24px;
  height: 24px;
}

If an element matching the selector inside the parentheses is passed into the slot, the declarations are applied directly to that element.

Key Rules and Limitations

While ::slotted() allows cross-boundary styling, it is subject to strict constraints designed to preserve DOM isolation:

  • Top-Level Nodes Only: ::slotted() can only target the direct children slotted into the component. It cannot target nested descendents of slotted nodes. For example, ::slotted(div p) or ::slotted(div) p are invalid and will not select a paragraph inside a slotted division.
  • Compound Selectors Only: The argument passed to ::slotted() must be a compound selector (such as p.intro or .active). Combinators like descendant ( ), child (>), or sibling (+, ~) cannot be used within the parenthesis.
  • Cascading Priority: Styles defined in the global or light DOM take precedence over ::slotted() rules. If an external stylesheet defines p { color: red; } and the shadow root defines ::slotted(p) { color: blue; }, the paragraph will appear red. The ::slotted() rules act essentially as fallback styles for slotted elements.
