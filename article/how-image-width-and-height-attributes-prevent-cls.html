How Image Width and Height Attributes Prevent CLS

Cumulative Layout Shift (CLS) occurs when elements on a web page move unexpectedly while content is still downloading, disrupting the user experience and hurting Core Web Vitals scores. Setting explicit width and height attributes on HTML <img> tags prevents this issue by allowing the browser to calculate the image's aspect ratio and reserve the necessary layout space before the image file finishes downloading.

The Cause of Image-Driven Layout Shift

When a browser parses an HTML document without image dimensions, it creates a zero-height placeholder for each image element. The browser then continues rendering the rest of the page layout, such as text and buttons, directly beneath that placeholder.

Once the image file finally downloads over the network, the browser suddenly discovers its true dimensions. It then reflows the page to make room for the new graphic, abruptly pushing all surrounding content downward. This sudden jump is a primary contributor to a poor CLS score.

How width and height Attributes Solve the Problem

Modern web browsers feature an internal user-agent stylesheet rule that calculates an image's intrinsic aspect ratio directly from its HTML width and height attributes:

img {
  aspect-ratio: attr(width) / attr(height);
}

Because this calculation happens during the initial HTML parsing phase, the browser knows the proportional space the image will occupy long before the image asset actually loads. It reserves the precise box dimensions within the Document Object Model (DOM), ensuring surrounding content stays in its intended position both before and after the asset arrives.

Working with Responsive Images

Adding fixed width and height attributes in HTML does not prevent an image from being responsive. In modern web design, developers use standard CSS rules alongside HTML attributes:

img {
  max-width: 100%;
  height: auto;
}

When this CSS is applied, the browser uses the HTML width and height strictly to determine the aspect ratio, while the CSS determines the fluid display size based on the parent container. As the container width changes across different screen sizes, the browser immediately calculates the correct corresponding height, maintaining layout stability across all devices.
